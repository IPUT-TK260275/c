# 07. 繰り返し

この章では、`while` を使って同じ処理を何度も実行する方法を学びます。

繰り返しは、プログラミングでとても重要です。「1 から 10 まで表示する」「入力された数を全部足す」「条件を満たすまで続ける」といった処理で使います。

## この章のゴール

| 学ぶこと | 例 |
| --- | --- |
| `while` の形 | `while (i < 10) { ... }` |
| カウンタ | `i = i + 1` |
| 合計を作る | `sum = sum + x` |
| 条件が変わるまで続ける | `while (条件)` |
| 実行の流れを追う | `.trace.txt` |

## `while` の基本形

```js
let i = 0;
while (i < 5) {
    Lib.print(i);
    Lib.print("\n");
    i = i + 1;
}
```

このコードは `0` から `4` までを表示します。

大事なのは、ループの中で `i = i + 1;` のように条件が変わる処理を書くことです。これがないと、繰り返しが終わりません。

## カウンタ

何回目かを数える変数をカウンタと呼びます。

```js
let i = 1;
while (i <= 10) {
    Lib.print(i);
    Lib.print("\n");
    i = i + 1;
}
```

## 合計

合計を作るときは、最初に `0` を入れておきます。

```js
let sum = 0;
let i = 1;
while (i <= 10) {
    sum = sum + i;
    i = i + 1;
}
Lib.print(sum);
Lib.print("\n");
```

`sum = sum + i;` は「今までの合計に `i` を足して、もう一度 `sum` に入れる」という意味です。

## 解くときの手順

1. 何を繰り返すか決める。
2. 何回繰り返すか、またはいつ終わるか決める。
3. カウンタや合計用の変数を最初に作る。
4. `while` の条件を書く。
5. ループの中でカウンタを更新する。
6. 最後に答えを出力する。

## よくあるミス

| ミス | 直し方 |
| --- | --- |
| 無限ループになる | カウンタを更新しているか確認する |
| 1 回多い、または少ない | `<` と `<=`、初期値、終了条件を見る |
| 合計が変になる | `sum` を最初に `0` にしているか確認する |
| 出力が横に続く | 必要な場所で `"\n"` を出す |
| ループの外に書くべき処理を中に書く | 毎回やる処理か、最後に 1 回だけやる処理か分ける |

## 各問題の解説

7章では、最初に「カウンタを何から始め、いつ止め、毎回どう変えるか」を決めます。合計や文字列を作る問題では、蓄積用の変数をループの前に用意します。

| 問題 | 解き方の要点 |
| --- | --- |
| `7.4.R1` | `cnt` が `50` 未満の間だけ `13` ずつ増えます。各反復後の値を trace に書きます。 |
| `7.4.R2` | `cnt` が `0` 以上の間だけ `13` ずつ減ります。条件が偽になった最後の値も確認します。 |
| `7.4.R3` | Collatz 型の更新です。偶数なら半分、奇数なら `3 * a + 1` にして、その都度出力を追います。 |
| `7.4.E1` | `cnt = a` から始め、`cnt <= 2 * a` の間、1ずつ増やして出力します。 |
| `7.4.E2` | `cnt = 2 * a` から始め、`cnt >= a` の間、1ずつ減らして出力します。 |
| `7.4.E3` | 1から `a` まで増やすループと、`a - 1` から1まで減らすループを分けます。 |
| `7.4.E4` | `cnt = 0` から始め、5ずつ増やして `a` 以下の間だけ出力します。 |
| `7.4.E5` | 正の奇数は `1, 3, 5, ...` なので、`cnt = 1` から2ずつ増やします。 |
| `7.4.E6` | 個数が `a` 個なので、出力した個数を数えるカウンタと、出力する奇数を分けます。 |
| `7.4.E7` | `a` 以下で最大の「3で割った余りが1」の数を見つけ、そこから3ずつ減らします。 |
| `7.4.E8` | 階乗は前の値に次の整数を掛けて作ります。`product` を更新しながら出力します。 |
| `7.4.E9` | 長さ `a` の文字列を作ります。奇数番目なら `"1"`、偶数番目なら `"0"` を足します。 |
| `7.4.E10` | `sum` に `cnt * cnt` を足しながら、`cnt` を1から `a` まで進めます。 |
| `7.4.E11` | `2` から `a` まで試し、`a % cnt === 0` なら割り切れる個数を増やします。 |

| `7.4.A2` | 文字列を後ろから前へ見て、1文字ずつ結果文字列に足します。 |
| `7.4.A3` | `String(a)` と `String(b)` の長さの差だけ空白を作り、その後に `b` を出力します。 |
| `7.4.A4` | 数字文字列を右から見て、3桁ごとにカンマを入れます。左端には余計なカンマを置きません。 |
| `7.4.A5` | 各文字を見て、`"-"` でない文字だけを結果文字列に足します。 |
