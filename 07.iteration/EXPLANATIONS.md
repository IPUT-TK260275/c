# 07. 反復文1: 問題別の詳しい解説

この章の問題は、`while` を使って「同じ形の処理を何回も行う」練習です。どの問題でも、まず「何を変えながら繰り返すか」を決めます。その変わる値をカウンタと呼びます。次に、開始値、続ける条件、更新の仕方を決めると、コードの形が見えてきます。

## 7.4.R1

- ループ変数: `cnt`
- 開始・停止・更新: `cnt = 11` から始め、`cnt < 50` の間だけ続けます。1回ごとに `cnt = cnt + 13` で13ずつ増やします。
- 追い方: `11 -> 24 -> 37 -> 50` と変わります。`50 < 50` は `false` なので、そこで止まります。
- 出力の形: ループを抜けた後の `cnt`、つまり `50` を1行で出力します。
- よくあるミス: 最後に条件を満たしていた `37` を答えにすることです。出力はループが終わった後の値です。

## 7.4.R2

- ループ変数: `cnt`
- 開始・停止・更新: `cnt = 50` から始め、`cnt >= 0` の間だけ続けます。1回ごとに `cnt = cnt - 13` で13ずつ減らします。
- 追い方: `50 -> 37 -> 24 -> 11 -> -2` と変わります。`-2 >= 0` は `false` なので、そこで止まります。
- 出力の形: ループを抜けた後の `cnt`、つまり `-2` を1行で出力します。
- よくあるミス: 0以上だった最後の値 `11` を出力すると考えることです。実際に印字されるのは、ループ終了後の値です。

## 7.4.R3

- ループ変数: `a`
- 開始・停止・更新: `a = 3` から始め、`a > 1` の間だけ続けます。偶数なら `a = a / 2`、奇数なら `a = 3 * a + 1` に更新します。
- 追い方: `3 -> 10 -> 5 -> 16 -> 8 -> 4 -> 2 -> 1` と変わります。
- 出力の形: 更新後の `a` を毎回1行ずつ出力します。`10`, `5`, `16`, `8`, `4`, `2`, `1` の順です。
- よくあるミス: 更新前の `a` を印字して、最初に `3` を出してしまうことです。

## 7.4.E1

- ループ変数: `cnt`
- 開始・停止・更新: 入力 `a` を読み、`cnt = a` から始めます。`cnt <= 2 * a` の間続け、`cnt = cnt + 1` で1ずつ増やします。
- 考え方: `a` から `2a` までなので、最初も最後も出力に含めます。
- 出力の形: `---` の後、`a` から `2 * a` までを1行に1つずつ出力します。
- よくあるミス: 条件を `cnt < 2 * a` にして、最後の `2 * a` を出し忘れることです。

## 7.4.E2

- ループ変数: `cnt`
- 開始・停止・更新: `cnt = 2 * a` から始めます。`cnt >= a` の間続け、`cnt = cnt - 1` で1ずつ減らします。
- 考え方: 大きい順なので、開始値を最大値にします。
- 出力の形: `---` の後、`2 * a` から `a` までを逆順に1行ずつ出力します。
- よくあるミス: 条件を `cnt > a` にしてしまい、最後の `a` を出し忘れることです。

## 7.4.E3

- ループ変数: 前半も後半も `cnt`
- 開始・停止・更新: 前半は `cnt = 1` から `cnt <= a` まで1ずつ増やします。後半は `cnt = a - 1` から `cnt >= 1` まで1ずつ減らします。
- 考え方: 頂点の `a` は前半で一度出すので、後半は `a - 1` から始めます。
- 出力の形: `---` の後、`1, 2, ..., a, a - 1, ..., 1` を1行ずつ出力します。
- よくあるミス: 後半を `cnt = a` から始めて、`a` を2回出してしまうことです。

## 7.4.E4

- ループ変数: `cnt`
- 開始・停止・更新: `cnt = 0` から始め、`cnt <= a` の間続けます。更新は `cnt = cnt + 5` です。
- 考え方: 5の倍数だけを出せばよいので、1ずつ増やしてから判定するより、最初から5ずつ増やすと素直です。
- 出力の形: `---` の後、`0, 5, 10, ...` のうち `a` 以下のものを1行ずつ出力します。
- よくあるミス: `cnt = cnt + 1` にして、すべての数を出してしまうことです。

## 7.4.E5

- ループ変数: `cnt`
- 開始・停止・更新: `cnt = 1` から始め、`cnt <= a` の間続けます。更新は `cnt = cnt + 2` です。
- 考え方: 正の奇数は `1, 3, 5, ...` なので、1から始めて2ずつ増やします。
- 出力の形: `---` の後、`a` 以下の正の奇数を小さい順に出力します。
- よくあるミス: `cnt = 0` から始めて偶数を出してしまうことです。

## 7.4.E6

- ループ変数: `cnt` と `odd_number`
- 開始・停止・更新: `cnt = 0` から始め、`cnt < a` の間続けます。`cnt` は1ずつ増やし、`odd_number` は1から始めて2ずつ増やします。
- 考え方: この問題の `a` は上限ではなく「何個出すか」です。個数を数える変数と、出す奇数そのものを分けると安全です。
- 出力の形: `---` の後、最初の `a` 個の奇数を1行ずつ出力します。
- よくあるミス: `odd_number <= a` を条件にすることです。それは「`a` 以下の奇数」になってしまいます。

## 7.4.E7

- ループ変数: `cnt`
- 開始・停止・更新: `cnt = a` から始め、`cnt >= 1` の間続けます。毎回 `cnt = cnt - 1` で1ずつ減らします。
- 考え方: 大きい順に調べながら、`cnt % 3 === 1` のときだけ印字します。
- 出力の形: `---` の後、`a` 以下の正の整数で3で割った余りが1のものを大きい順に出力します。
- よくあるミス: `cnt = cnt - 1` を `if` の中に入れてしまうことです。条件に合わない数で止まり、無限ループになります。

## 7.4.E8

- ループ変数: `cnt`
- 開始・停止・更新: `cnt = 1` から始め、`cnt <= a` の間続けます。毎回 `cnt = cnt + 1` で進めます。
- 累積する変数: `factorial` です。最初は `1` にし、毎回 `factorial = factorial * cnt` で階乗を育てます。
- 出力の形: `---` の後、`1!`, `2!`, `3!`, ..., `a!` の値を1行ずつ出力します。
- よくあるミス: `factorial` を `0` で始めることです。掛け算では一度0になるとずっと0です。

## 7.4.E9

- ループ変数: `cnt`
- 開始・停止・更新: `cnt = 0` から始め、`cnt < a` の間続けます。毎回 `cnt = cnt + 1` で進めます。
- 累積する変数: `s` です。空文字 `""` から始め、偶数番目なら `"1"`、奇数番目なら `"0"` を後ろにつなげます。
- 出力の形: `---` の後、長さ `a` の `1010...` という文字列を1行で出力します。
- よくあるミス: ループの中で毎回改行することです。この問題は1つの文字列を作って最後に出します。

## 7.4.E10

- ループ変数: `cnt`
- 開始・停止・更新: `cnt = 1` から始め、`cnt <= a` の間続けます。毎回 `cnt = cnt + 1` で進めます。
- 累積する変数: `sum` です。最初は `0` にし、毎回 `cnt * cnt` を足します。
- 出力の形: `---` の後、`1^2 + 2^2 + ... + a^2` の合計を1行で出力します。
- よくあるミス: `sum = sum + cnt` として、二乗ではなく普通の合計にしてしまうことです。

## 7.4.E11

- ループ変数: `cnt`
- 開始・停止・更新: `cnt = 2` から始め、`cnt <= a` の間続けます。毎回 `cnt = cnt + 1` で進めます。
- 累積する変数: `num` です。`a % cnt === 0` なら、割り切れる数として `num` を1増やします。
- 出力の形: `---` の後、`2` から `a` までの中で `a` を割り切れる数の個数を1行で出力します。
- よくあるミス: 条件を `cnt < a` にして、`a` 自身を数え忘れることです。

## 7.4.A1

- ループ変数: `cnt`
- 開始・停止・更新: `cnt = 0` から始め、`cnt < Lib.length(a)` の間続けます。毎回 `cnt = cnt + 1` で次の文字へ進みます。
- 累積する変数: `num` です。文字 `ch` が `"A"` 以上 `"Z"` 以下なら、大文字として数えます。
- 出力の形: `---` の後、文字列 `a` に含まれる英大文字の数を1行で出力します。
- よくあるミス: `cnt <= Lib.length(a)` にすることです。最後の文字のインデクスは `Lib.length(a) - 1` です。

## 7.4.A2

- ループ変数: `cnt`
- 開始・停止・更新: `cnt = Lib.length(a) - 1` から始め、`cnt >= 0` の間続けます。毎回 `cnt = cnt - 1` で左へ戻ります。
- 累積する変数: `s` です。空文字から始め、後ろの文字から順に追加します。
- 出力の形: `---` の後、入力文字列を逆順にした文字列を1行で出力します。
- よくあるミス: `cnt = Lib.length(a)` から始めることです。その位置には文字がありません。

## 7.4.A3

- ループ変数: `cnt`
- 開始・停止・更新: `cnt = 0` から始め、`cnt < Lib.length(a_string) - Lib.length(b_string)` の間続けます。毎回 `cnt = cnt + 1` で空白を1つずつ出します。
- 考え方: 数値 `a` と `b` は、右揃え用に文字列に変換して桁数を調べます。
- 出力の形: `---` の後、1行目に `a`、2行目に必要な空白を置いてから `b` を出し、右端をそろえます。
- よくあるミス: 空白の数を「大きい数 - 小さい数」で計算することです。必要なのは値の差ではなく、文字列にしたときの桁数の差です。

## 7.4.A4

- ループ変数: `cnt`
- 開始・停止・更新: `cnt = 0` から始め、`cnt < Lib.length(a_string)` の間続けます。毎回 `cnt = cnt + 1` で次の文字へ進みます。
- 累積する変数: `s` です。必要ならコンマを追加してから、現在の文字を追加します。
- 出力の形: `---` の後、右から3桁ごとにコンマを入れた文字列を1行で出力します。
- よくあるミス: 左から3文字ごとにコンマを入れることです。コンマの位置は「右から数えて3桁ごと」で考えます。

## 7.4.A5

- ループ変数: `cnt`
- 開始・停止・更新: `cnt = 0` から始め、`cnt < Lib.length(a)` の間続けます。毎回 `cnt = cnt + 1` で次の文字へ進みます。
- 累積する変数: `s` です。現在の文字が `"-"` でなければ `s` に追加します。
- 出力の形: `---` の後、入力文字列からハイフンをすべて取り除いた文字列を1行で出力します。
- よくあるミス: `cnt` の更新を `if` の中に入れてしまうことです。ハイフンのときに進まなくなります。
