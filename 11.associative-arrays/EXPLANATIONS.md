# 11. 連想配列: 問題別の詳しい解説

この章の問題では、番号で値を取り出す配列ではなく、キーで値を取り出す連想配列を使います。固定されたキーを読むときは `student.math` のような属性記法が読みやすく、キーが変数に入っているときは `a[key]` を使います。入力された連想配列や連想配列の配列は、まず `JSON.parse(Lib.input())` で変換します。

## 11.10.E1

- 読むもの・入力: `student_id`、`japanese`、`math`、`english` を持つ連想配列が1つ入力されます。
- 最初にすること: `let student = JSON.parse(Lib.input());` のように、入力文字列を連想配列に変換します。
- 取り出す値: 数学の点数なので、キーは `"math"` です。`student.math` または `student["math"]` で取り出します。
- 出力の形: `---` の次の行に数学の点数だけを印字します。
- よくあるミス: `student_id` や `japanese` を出してしまうことです。問題が求めているキーは `math` です。

## 11.10.E2

- 読むもの・入力: 1人分の成績を表す連想配列が入力されます。
- 取り出す値: `student.japanese`、`student.math`、`student.english` の3つです。
- 作る式: `student.japanese + student.math + student.english` で総合点を作ります。
- 出力の形: `---` の次の行に総合点を印字します。
- よくあるミス: `student_id` も足してしまうことです。学籍番号は点数ではないので、合計に入れません。

## 11.10.E3

- 読むもの・入力: 複数人分の成績連想配列を要素に持つ配列が入力されます。
- 最初にすること: `let A = JSON.parse(Lib.input());` で、配列に変換します。`A[i]` が1人分の連想配列です。
- 使う反復: `i = 0` から `i < Lib.length(A)` の間、各学生を1人ずつ見ます。
- 累積する変数: 数学の合計 `sum_math` を0から始め、各回で `sum_math = sum_math + A[i].math;` とします。
- 出力の形: `---` の次の行に `sum_math / Lib.length(A)` を印字します。
- よくあるミス: `A.math` と書くことです。`A` は学生全体の配列なので、まず `A[i]` で1人分を取り出してから `.math` を読みます。

## 11.10.E4

- 読むもの・入力: 複数人分の成績連想配列を要素に持つ配列が入力されます。
- 各学生で計算するもの: `total = student.japanese + student.math + student.english` です。
- 最大値の持ち方: `max_total` に、これまで見た総合点の最大値を入れます。最初の学生を見たときに初期化するか、十分小さい値から始めます。
- 同点の扱い: 最大値を更新したら、答えの配列をその学生だけに作り直します。同じ最大値の学生を見つけたら、答えの配列に学籍番号を追加します。
- 出力の形: `---` の後、総合点が最大の学生の `student_id` を1行ずつ印字します。同点が複数人いれば複数行になります。
- よくあるミス: 最大値の学生を1人だけ変数に入れて、同点の学生を消してしまうことです。この問題は同点をすべて出力します。

## 11.10.A1

- 読むもの・入力: 各ユーザについて、`user_id` と、そのユーザがフォローしているユーザIDの配列 `following` を持つ連想配列の配列が入力されます。
- 求めたいもの: 「誰を何人がフォローしているか」です。これは、各ユーザの `following` の中に現れる回数を数える問題です。
- 使う連想配列: `id_to_followers` のような連想配列を作り、キーをユーザID、値をフォロワー数にします。ユーザIDは数値ですが、連想配列のキーとして使うと文字列のように扱われます。
- 数え方: 外側の反復で各ユーザを見ます。内側の反復でそのユーザの `following` 配列を見ます。フォロー先ID `id` を見つけたら、`id_to_followers[id]` を1増やします。まだキーがなければ、先に0を入れてから増やします。
- 最大値の探し方: 数え終わったら `Object.keys(id_to_followers)` で全ユーザIDを取り出し、フォロワー数が最大のIDを探します。同点があればすべて残します。
- 出力の形: `---` の後、フォロワー数が最大のユーザIDを1行ずつ印字します。
- よくあるミス: `following` の長さをそのユーザ自身のフォロワー数だと思うことです。`following` は「その人がフォローしている人数」であり、「その人をフォローしている人数」ではありません。逆向きに数え直す必要があります。

## 連想配列問題を解くときの型の見分け方

- `A` が配列なら、まず `A[i]` で1件を取り出します。
- `A[i]` が連想配列なら、`A[i].math` や `A[i].following` のようにキーで値を取り出します。
- `A[i].following` が配列なら、さらに `A[i].following[j]` のように番号で中身を取り出します。
- つまり、`配列 -> 連想配列 -> 配列` のように入れ子になっているデータでは、今見ている値がどの型なのかを1段ずつ確認します。

## 集計問題の基本形

1. 空の連想配列を作ります。例: `let counts = {};`
2. データを1つずつ見ます。
3. 数えたいキーがまだなければ、`counts[key] = 0;` で作ります。
4. 見つけた分だけ `counts[key] = counts[key] + 1;` で増やします。
5. 最後に `Object.keys(counts)` でキー一覧を取り出し、最大値や必要な値を探します。
