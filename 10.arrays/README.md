# 10. 配列

この章では、複数の値をまとめて扱う配列を学びます。

配列は、値を順番に並べたものです。たとえば `[10, 20, 30]` は 3 つの数値を持つ配列です。大量の入力をまとめて処理したいときや、同じ処理を全要素に行いたいときに使います。

## この章のゴール

| 学ぶこと | 例 |
| --- | --- |
| 配列を作る | `[10, 20, 30]` |
| 要素を取り出す | `a[0]` |
| 長さを調べる | `Lib.length(a)` |
| 配列を前から見る | `while (i < Lib.length(a))` |
| 配列に追加する | `Lib.push(a, x)` |
| 入力から配列を作る | `JSON.parse(Lib.input())` |

## 配列の基本

配列は `[` と `]` で作ります。

```js
let a = [10, 20, 30];
```

要素は 0 番目から始まります。

```js
Lib.print(a[0]); // 10
Lib.print("\n");
```

最後の要素は、長さより 1 小さい番号です。

```js
let last = a[Lib.length(a) - 1];
```

## 配列の長さ

この教材では、配列の長さを `Lib.length(a)` で調べます。

```js
let a = [10, 20, 30];
Lib.print(Lib.length(a));
Lib.print("\n");
```

出力は `3` です。

## 配列を前から見る

```js
let a = [10, 20, 30];
let i = 0;
while (i < Lib.length(a)) {
    Lib.print(a[i]);
    Lib.print("\n");
    i = i + 1;
}
```

配列の添字は 0 から始まるので、条件は `i < Lib.length(a)` になります。

## 入力から配列を作る

入力が次のように配列リテラルで与えられる問題があります。

```text
[2, 3, 7, 5]
```

この場合は `JSON.parse` を使います。

```js
let a = JSON.parse(Lib.input());
```

## 配列に値を追加する

```js
let a = [];
Lib.push(a, 10);
Lib.push(a, 20);
```

このあと `a` は `[10, 20]` になります。

## よくあるミス

| ミス | 直し方 |
| --- | --- |
| 最初の要素を `a[1]` だと思う | 最初は `a[0]` |
| 最後の要素を `a[Lib.length(a)]` と書く | `a[Lib.length(a) - 1]` |
| ループが 1 回多い | 条件を `i < Lib.length(a)` にする |
| `JSON.parse` を忘れる | 配列入力は `JSON.parse(Lib.input())` |
| 最大値の初期値が変 | 最初の要素 `a[0]` から始める |
