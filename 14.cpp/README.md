# 14. C/C++ の基礎

この章では、これまで JavaScript で学んだ値、変数、入力、条件分岐、繰り返しを C++ で書き直します。

JavaScript は `node ファイル名.js` でそのまま実行できました。C++ は最初にソースコードをコンパイルして実行ファイルを作り、その実行ファイルを動かします。書き方は少し増えますが、処理の組み立て方はこれまでの章と同じです。

## この章のゴール

| 学ぶこと | C++での書き方 |
| --- | --- |
| 整数、小数、真偽値、文字列 | `int`, `double`, `bool`, `string` |
| 画面への出力 | `cout << 値;` |
| 1行の入力 | `getline(cin, 変数);` |
| 文字列から数値への変換 | `stoi(文字列)`, `stod(文字列)` |
| 条件分岐 | `if`, `else if`, `else` |
| 繰り返し | `while`, `for` |
| 文字列の一部を取り出す | `substr(開始位置, 長さ)` |

## C++プログラムの基本形

この章のプログラムは、基本的に次の形で作ります。

```cpp
#include <iostream>
#include <string>

using namespace std;

int main() {
    cout << unitbuf << boolalpha;

    // ここに処理を書く
}
```

`#include` は、プログラムで使う道具を読み込むための宣言です。

| 宣言 | 主に使えるようになるもの |
| --- | --- |
| `#include <iostream>` | `cin`, `cout` |
| `#include <string>` | `string`, `getline`, `stoi`, `stod` |
| `#include <vector>` | `vector` |
| `#include <map>` | `map` |

`int main()` の中に書いた処理が上から順番に実行されます。文の最後には原則としてセミコロン `;` が必要です。

## JavaScriptとの対応

### 変数と型

JavaScriptでは多くの場合 `let` を使いました。

```js
let age = 18;
let height = 157.5;
let name = "Alice";
```

C++では、変数名の前に値の型を書きます。

```cpp
int age = 18;
double height = 157.5;
string name = "Alice";
```

| 値 | JavaScript | C++ |
| --- | --- | --- |
| 整数 | `let a = 10;` | `int a = 10;` |
| 小数 | `let a = 3.14;` | `double a = 3.14;` |
| 真偽値 | `let a = true;` | `bool a = true;` |
| 文字列 | `let a = "Hello";` | `string a = "Hello";` |

### 出力

JavaScriptの次のコードは、

```js
Lib.print("Hello\n");
```

C++では次のように書けます。

```cpp
cout << "Hello\n";
```

複数の値は `<<` でつなげられます。

```cpp
cout << name << ": " << price << " yen\n";
```

### 入力

文字列を1行読む場合は、先に `string` 型の変数を作ってから `getline` を使います。

```cpp
string name;
getline(cin, name);
```

整数や小数は `cin >> 変数;` で直接読むこともできます。

```cpp
int count;
double price;
cin >> count;
cin >> price;
```

`cin >>` の直後に `getline` を使うと、入力に残った改行を `getline` が読んでしまうことがあります。その場合は、先に次を書いて改行を捨てます。

```cpp
cin.ignore();
getline(cin, name);
```

## コンパイルして実行する

たとえば `14.6.E1.cpp` をコンパイルするには、リポジトリのルートで次を実行します。

```bash
g++ -std=c++17 -Wall -Wextra 14.cpp/14.6.E1.cpp -o /tmp/14.6.E1
```

成功すると `/tmp/14.6.E1` という実行ファイルができます。次のように実行します。

```bash
/tmp/14.6.E1
```

入力をまとめて渡す例です。

```bash
printf 'Apples\n180\n4\nPeaches\n220\n5\n' | /tmp/14.6.E1
```

出力は次の形になります。

```text
---
Apples: 720 yen
Peaches: 1100 yen
===
Total: 1820 yen
```

## 練習問題の解説

### 14.6.E1 商品ごとの代金と合計

商品名、単価、個数を2商品分読みます。商品ごとの代金は `単価 * 個数`、総額は2商品の代金の和です。

商品名には `Fried Chicken` のように空白が入る可能性があるため、商品名は `getline` で1行すべてを読みます。数値を `cin >>` で読んだあと、次の商品名を `getline` で読む前に `cin.ignore()` が必要です。

### 14.6.E2 5つの数値の平均

平均は「合計を個数で割った値」です。小数も入力されるため、合計と入力値には `double` を使います。

```cpp
double total = 0;
total += value;
cout << total / 5;
```

`int` を使うと小数部分が失われるので注意してください。

### 14.6.E3 分を時間と分に分ける

`a` 分に含まれる時間は `a / 60`、残りの分は `a % 60` です。

```cpp
int hours = a / 60;
int minutes = a % 60;
```

整数どうしの割り算では小数部分が切り捨てられるため、時間の計算にそのまま利用できます。

### 14.6.E4 3つの整数がすべて異なるか

3組すべてを比較します。

```cpp
a != b && b != c && a != c
```

`a != b && b != c` だけでは、`a` と `c` が同じ場合を見逃します。

### 14.6.E5 欠席と遅刻から出席要件を判定する

遅刻3回を欠席1回として数えるので、換算後の欠席回数は次の式です。

```cpp
absences + late_arrivals / 3
```

この値が7未満なら出席要件を満たします。`late_arrivals / 3` は整数の割り算なので、余った遅刻は欠席に換算されません。

### 14.6.E6 文字列の真ん中の文字

文字列の長さが奇数なら、中央の位置は `長さ / 2` です。C++の添字は0から始まります。

```cpp
text[text.size() / 2]
```

`abc` の長さは3で、`3 / 2` は1です。`text[1]` は2文字目の `b` になります。

### 14.6.E7 郵便番号にハイフンを入れる

`substr` で最初の3文字と、それ以降の文字を取り出します。

```cpp
postal_code.substr(0, 3)
postal_code.substr(3)
```

この2つの間に `-` を出力します。

### 14.6.E8 メールアドレス形式の簡易判定

次の3条件を順に確認します。

1. `@` が存在する。
2. `@` が先頭ではなく、2つ目の `@` が存在しない。
3. `@` より後ろに `.` が存在する。

`string::find` は見つかった位置を返します。見つからない場合は `string::npos` を返します。

```cpp
size_t at = address.find('@');
```

2つ目を探すときは、最初の `@` の次の位置から検索します。

```cpp
address.find('@', at + 1)
```

### 14.6.E9 正の奇数を順番に出力する

1から始め、毎回2を足すと奇数だけを処理できます。

```cpp
for (int value = 1; value <= limit; value += 2) {
    cout << value << '\n';
}
```

### 14.6.E10 1からaまでの階乗

階乗の値を1で初期化し、1、2、3、...と順番に掛けます。掛けるたびに現在の階乗を出力します。

```cpp
long long factorial = 1;
for (int value = 1; value <= limit; ++value) {
    factorial *= value;
    cout << factorial << '\n';
}
```

階乗はすぐ大きくなるため、通常の `int` より広い `long long` を使っています。

### 14.6.E11 k行目にkをk個出力する

行を数える繰り返しと、その行の中で値を出す繰り返しを組み合わせます。

カンマは値の前に無条件で出すのではなく、2個目以降の前だけに出します。これにより行末に余分なカンマが付きません。

### 14.6.A1 3つの整数を昇順に並べる

3つの整数を `array` に入れ、`sort` で小さい順に並べます。

```cpp
array<int, 3> values;
sort(values.begin(), values.end());
```

`sort` を使うには `#include <algorithm>`、`array` を使うには `#include <array>` が必要です。

## よくあるミス

| ミス | 確認すること |
| --- | --- |
| コンパイルせずに `.cpp` を実行しようとする | 先に `g++` で実行ファイルを作る |
| 文末の `;` を忘れる | エラーに表示された行と、その1つ前の行を見る |
| 文字列に空白があると途中までしか読めない | 文字列は `getline` で読む |
| `cin >>` の直後の `getline` が空になる | `cin.ignore()` で残った改行を捨てる |
| `=` と `==` を混同する | 代入は `=`、比較は `==` |
| 真偽値が `1`、`0` で表示される | `cout << boolalpha;` を設定する |
| 整数の平均で小数が消える | 合計や入力値に `double` を使う |
| 出力が不正解になる | `---`、空白、カンマ、改行を出力例と揃える |
