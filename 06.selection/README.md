# 06. 条件分岐

この章では、条件によって処理を変える `if`、`else`、`else if` を学びます。

プログラムは、いつも同じ処理だけをするわけではありません。「もし点数が 60 点以上なら合格」「もし入力が 0 なら特別な処理」のように、条件で分ける場面がたくさんあります。

## この章のゴール

| 学ぶこと | 例 |
| --- | --- |
| 条件が真のときだけ実行する | `if` |
| 条件が偽のときの処理を書く | `else` |
| 複数の条件を順番に調べる | `else if` |
| 条件を組み合わせる | `&&`, `||`, `!` |
| 入れ子の条件を書く | `if` の中の `if` |

## `if`

`if` は、条件が `true` のときだけ中身を実行します。

```js
if (score >= 60) {
    Lib.print("pass\n");
}
```

## `else`

`else` は、`if` の条件が `false` だったときに実行されます。

```js
if (score >= 60) {
    Lib.print("pass\n");
} else {
    Lib.print("fail\n");
}
```

## `else if`

条件が複数あるときに使います。

```js
if (score >= 80) {
    Lib.print("A\n");
} else if (score >= 60) {
    Lib.print("B\n");
} else {
    Lib.print("C\n");
}
```

上から順番に調べて、最初に当てはまったところだけ実行されます。

## 条件の組み合わせ

| 書き方 | 意味 |
| --- | --- |
| `a && b` | `a` かつ `b` |
| `a || b` | `a` または `b` |
| `!a` | `a` ではない |

範囲を調べる例です。

```js
if (1 <= x && x <= 10) {
    Lib.print("ok\n");
}
```

`1 <= x <= 10` とは書きません。

## 解くときの手順

1. 入力を読む。
2. どの条件で出力が変わるか、問題文から探す。
3. 条件を `if` に書く。
4. 出力例と同じ文字、空白、改行を出す。
5. 境界の値で試す。たとえば `60`、`59`、`0` など。

## よくあるミス

| ミス | 直し方 |
| --- | --- |
| 比較で `=` を使う | `===` を使う |
| 範囲判定を `a < b < c` と書く | `a < b && b < c` と書く |
| `else` に条件を書く | 条件を書くなら `else if (...)` |
| 境界値が 1 つずれる | `<` と `<=` を問題文に合わせる |
| どの分岐でも改行を出していない | 各出力の最後に `\n` を確認する |
