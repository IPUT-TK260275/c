# 06. 条件分岐

この章では、条件によって処理を変える `if`、`else`、`else if` を学びます。

プログラムは、いつも同じ処理だけをするわけではありません。「もし点数が 60 点以上なら合格」「もし入力が 0 なら特別な処理」のように、条件で分ける場面がたくさんあります。

## この章のゴール

| 学ぶこと | 例 |
| --- | --- |
| 条件が真のときだけ実行する | `if` |
| 条件が偽のときの処理を書く | `else` |
| 複数の条件を順番に調べる | `else if` |
| 条件を組み合わせる | `&&`, `||`, `!` |
| 入れ子の条件を書く | `if` の中の `if` |

## `if`

`if` は、条件が `true` のときだけ中身を実行します。

```js
if (score >= 60) {
    Lib.print("pass\n");
}
```

## `else`

`else` は、`if` の条件が `false` だったときに実行されます。

```js
if (score >= 60) {
    Lib.print("pass\n");
} else {
    Lib.print("fail\n");
}
```

## `else if`

条件が複数あるときに使います。

```js
if (score >= 80) {
    Lib.print("A\n");
} else if (score >= 60) {
    Lib.print("B\n");
} else {
    Lib.print("C\n");
}
```

上から順番に調べて、最初に当てはまったところだけ実行されます。

## 条件の組み合わせ

| 書き方 | 意味 |
| --- | --- |
| `a && b` | `a` かつ `b` |
| `a || b` | `a` または `b` |
| `!a` | `a` ではない |

範囲を調べる例です。

```js
if (1 <= x && x <= 10) {
    Lib.print("ok\n");
}
```

`1 <= x <= 10` とは書きません。

## 解くときの手順

1. 入力を読む。
2. どの条件で出力が変わるか、問題文から探す。
3. 条件を `if` に書く。
4. 出力例と同じ文字、空白、改行を出す。
5. 境界の値で試す。たとえば `60`、`59`、`0` など。

## よくあるミス

| ミス | 直し方 |
| --- | --- |
| 比較で `=` を使う | `===` を使う |
| 範囲判定を `a < b < c` と書く | `a < b && b < c` と書く |
| `else` に条件を書く | 条件を書くなら `else if (...)` |
| 境界値が 1 つずれる | `<` と `<=` を問題文に合わせる |
| どの分岐でも改行を出していない | 各出力の最後に `\n` を確認する |

## 各問題の解説

6章では、問題文の「なら」「そうでなければ」を `if` / `else` に変換します。境界値が出てくる問題では、`<` と `<=` の違いを必ず確認してください。

| 問題 | 解き方の要点 |
| --- | --- |
| `6.5.R1.1` | trace 問題です。条件が `true` のときだけ `if` ブロックを表に追加します。 |
| `6.5.R1.2` | 入力を変えたときに、同じ `if` が実行されるかどうかを表に反映します。 |
| `6.5.R2.1` | `if` と `else` のどちらか一方だけが実行されます。実行されなかった側は表に書きません。 |
| `6.5.R2.2` | 条件式の評価結果を先に決め、その結果に対応するブロックだけを追います。 |
| `6.5.R3` | 入れ子の条件分岐です。外側の条件を通った後で、内側の条件を調べます。 |
| `6.5.E1` | 1つの条件で出力が分かれる基本問題です。問題文の条件をそのまま比較式にします。 |
| `6.5.E2` | `if` と `else` を使い、条件が成り立つ場合と成り立たない場合の出力を分けます。 |
| `6.5.E3` | 複数条件を `&&` または `||` で組み合わせる問題です。 |
| `6.5.E4` | 数値の大小を比べ、条件に応じて出力する値を変えます。 |
| `6.5.E5` | `a % b` のような余りを使って条件を作ります。 |
| `6.5.E6` | 範囲判定は `lower <= x && x <= upper` の形で書きます。 |
| `6.5.E7` | 3つ以上の場合分けは `else if` を使うと読みやすくなります。 |
| `6.5.E8` | 条件の順番が大事です。より限定的な条件を先に調べると安全です。 |
| `6.5.E9` | 条件に応じて計算式そのものを変える問題です。出力処理は最後にまとめると見通しがよくなります。 |

| `6.5.E12` | 入力の形式を条件で検証します。長さや文字種を分けて考えます。 |
| `6.5.E13` | 複数の出力形式があるときは、分岐ごとに完成形の出力を作ります。 |
