# 05. ブロックと変数

この章では、変数の作り方、値の入れ方、使える範囲を学びます。

変数は「値に名前を付ける箱」のようなものです。ただし、JavaScript では変数を使える場所が決まっています。この章では、そのルールをゆっくり確認します。

## この章のゴール

| 学ぶこと | 例 |
| --- | --- |
| 変数を作る | `let x;` |
| 変数に値を入れる | `x = 10;` |
| 作ると同時に値を入れる | `let x = 10;` |
| 変数を使って計算する | `x + y` |
| ブロックの範囲を理解する | `{ ... }` |

## 変数を作る

`let` で変数を作ります。

```js
let price;
```

値を入れるには `=` を使います。

```js
price = 120;
```

作るのと同時に値を入れることもできます。

```js
let price = 120;
```

## 代入と比較は違う

`=` は「右の値を左の変数に入れる」です。

```js
let x = 10;
x = 20;
```

等しいか調べるときは `===` です。

```js
let same = x === 20;
```

## ブロック

`{` から `}` までをブロックと呼びます。

```js
{
    let x = 10;
    Lib.print(x);
    Lib.print("\n");
}
```

`let` で作った変数は、基本的にそのブロックの中で使います。ブロックの外から使おうとすると、`ReferenceError` になることがあります。

## 初期化されていない変数

値を入れていない変数の中身は `undefined` です。

```js
let x;
Lib.print(x);
Lib.print("\n");
```

計算に使う変数には、先に値を入れてください。

## よくあるミス

| ミス | 直し方 |
| --- | --- |
| `let` なしで変数を使う | 先に `let x = ...;` と書く |
| 変数名のスペルが違う | 宣言した名前と使う名前を見比べる |
| ブロックの外で変数を使う | 変数を使う場所と作った場所を確認する |
| 比較で `=` を使う | 比較は `===` |
| 値を入れる前に計算する | 先に初期化する |

## 各問題の解説

5章の問題は、出力だけでなく「どの行でどの変数の値が変わったか」を追う練習です。コードを一気に読まず、1行ずつ状態表へ写していきます。

| 問題 | 解き方の要点 |
| --- | --- |
| `5.4.E1` | 代入文が実行されるたびに、左辺の変数だけが新しい値になります。`Lib.print` の行では変数の値は変わりません。 |
| `5.4.E2` | ブロック内で宣言された変数がどの範囲で使えるかを見ます。同じ名前でも、内側ブロックの変数と外側ブロックの変数を混同しないようにします。 |
| `5.4.E3` | 値の更新が連続する問題です。右辺を先に計算し、その結果を左辺に代入する、という順序で追います。 |
