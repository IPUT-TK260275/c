# 04. 値と式

この章では、計算、比較、文字列操作、型変換を学びます。

「式」は、計算して 1 つの値になるものです。たとえば `1 + 2` は `3` になり、`a < b` は `true` または `false` になります。

## 数値と計算

よく使う演算子です。

| 書き方 | 意味 |
| --- | --- |
| `a + b` | 足し算 |
| `a - b` | 引き算 |
| `a * b` | 掛け算 |
| `a / b` | 割り算 |
| `a % b` | 余り |

例です。

```js
let price = 120;
let count = 5;
Lib.print(price * count);
Lib.print("\n");
```

## 比較

比較の結果は `true` または `false` です。

| 書き方 | 意味 |
| --- | --- |
| `a === b` | 等しい |
| `a !== b` | 等しくない |
| `a < b` | `a` が `b` より小さい |
| `a <= b` | `a` が `b` 以下 |
| `a > b` | `a` が `b` より大きい |
| `a >= b` | `a` が `b` 以上 |

比較で `=` を使わないでください。`=` は代入です。比較には `===` を使います。

## 論理演算

複数の条件を組み合わせます。

| 書き方 | 意味 |
| --- | --- |
| `a && b` | `a` かつ `b` |
| `a || b` | `a` または `b` |
| `!a` | `a` ではない |

たとえば、`x` が 1 以上 10 以下か調べるならこうです。

```js
let ok = 1 <= x && x <= 10;
```

`1 <= x <= 10` とは書きません。

## 文字列

文字列は `"` で囲みます。

```js
let s = "hello";
```

よく使う操作です。

| 書き方 | 意味 |
| --- | --- |
| `s.length` | 文字列の長さ |
| `s.charAt(0)` | 0 番目の文字 |
| `s.indexOf("e")` | `"e"` が最初に出る位置 |
| `s.slice(1, 4)` | 1 番目から 4 番目の手前まで取り出す |
| `s + t` | 文字列をつなげる |

JavaScript の位置番号は 0 から始まります。最初の文字は 1 番目ではなく 0 番目です。

## 型変換

入力は最初、文字列として読まれます。

```js
let s = Lib.input();
```

数値として計算したいときは、`Number(...)` を使います。

```js
let n = Number(Lib.input());
```

出力用に文字列へ変えたいときは、`String(...)` を使えます。

```js
let s = String(123);
```

## よくあるミス

| ミス | 直し方 |
| --- | --- |
| 比較で `=` を使う | `===` を使う |
| 範囲判定を `a < b < c` と書く | `a < b && b < c` と書く |
| 入力した数が計算できない | `Number(Lib.input())` にする |
| 文字列の最初を 1 番目だと思う | 最初は 0 番目 |
| `slice` の終わり位置を含めてしまう | 終わり位置の手前まで取る |

## 各問題の解説

4章は「式を作る」章です。答えを直接出すより、問題文の条件を数値式、比較式、文字列式に直してから出力すると間違いにくくなります。

### 4.1 数値

| 問題 | 解き方の要点 |
| --- | --- |
| `4.1.E1` | 合計代金 `a * m + b * n` を作り、`5000` から引きます。 |
| `4.1.E2` | 卵が余る数なので、余り演算子 `%` を使って `a % b` を出します。 |
| `4.1.E3` | 1人分は整除算の商です。`(a - a % b) / b` で求めます。 |
| `4.1.E4` | 税込代金は `198 * a * 1.1` です。小数点以下切り捨ては `Math.floor` を使います。 |
| `4.1.E5` | 年齢差は負にならない値なので `Math.abs(a - b)` を使います。 |
| `4.1.E6` | 円の面積は `Math.PI * r * r` なので、半径は `Math.sqrt(a / Math.PI)` です。 |
| `4.1.E7` | 分を時間と分に分けます。時間は商、分は `a % 60` です。 |
| `4.1.A1` | 秒を時間、分、秒に分けます。まず時間、残り秒、分、最後の秒の順に考えます。 |

### 4.2 真理値

| 問題 | 解き方の要点 |
| --- | --- |
| `4.2.E1` | 負の数かどうかは `a < 0` です。 |
| `4.2.E2` | 100以上かどうかは `a >= 100` です。 |
| `4.2.E3` | `a * a === b` で2乗と一致するか調べます。 |
| `4.2.E4` | どちらか一方がもう一方の2乗なので、`a * a === b || b * b === a` です。 |
| `4.2.E5` | 商は `(a - a % b) / b`、余りは `a % b` です。この2つを比較します。 |
| `4.2.E6` | 3つがすべて異なるとは、`a !== b && b !== c && c !== a` です。 |
| `4.2.E7` | 総額 `a * n` が `2000` を超えるかを比較します。 |
| `4.2.E8` | 重量条件と個数条件の両方が必要なので `&&` でつなぎます。 |
| `4.2.E9` | タルト総数 `12 * m` が `n` で割り切れるかを `%` で調べます。 |
| `4.2.E10` | 2026年4月1日からの日数を考え、曜日の周期 `7` を使って土日を判定します。 |
| `4.2.A1` | どの辺が斜辺でもよいので、3通りのピタゴラス判定を `||` でつなぎます。 |
| `4.2.A2` | 遅刻3回を欠席1回に換算します。`a + (b - b % 3) / 3 < 7` が基本です。 |
