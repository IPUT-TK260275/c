# 04. 値と式 問題別の詳しい解説

4章では、問題文を「数値の式」「真偽値の式」「文字列の式」に直す練習をします。まず入力を読む、次に式を作る、最後に `---` と答えを出す、という順番で考えると解きやすいです。

## 4.1 数値

### 4.1.E1

- 入力: りんごの単価 `a`、個数 `m`、桃の単価 `b`、個数 `n` を数値で読みます。
- 式: 合計は `a * m + b * n` です。5000円札で払うので、おつりは `5000 - 合計` です。
- 出力: `---` の次の行におつりだけを出します。
- 注意: 5000円で買える前提なので、足りるかどうかの `if` は不要です。

### 4.1.E2

- 入力: 卵の数 `a`、人数 `b` を読みます。
- 式: 余る数は余りなので `a % b` です。
- 出力: `---` の次に余りを出します。
- 注意: `/` は割り算の結果、`%` は余りです。ここでは `%` を使います。

### 4.1.E3

- 入力: 卵の数 `a`、人数 `b` を読みます。
- 式: 1人が受け取る数は、余りを除いた割り算の商です。`(a - a % b) / b` と考えます。
- 出力: 商を1行で出します。
- 注意: 普通の `a / b` だと小数になる場合があります。余った卵は配らないので整数の商にします。

### 4.1.E4

- 入力: りんごの個数 `a` を読みます。
- 式: 税抜は `198 * a`、税込は `198 * a * 1.1` です。小数点以下切り捨てなので `Math.floor(...)` で囲みます。
- 出力: 税込代金を出します。
- 注意: `1.1` を掛けたあとに切り捨てます。先に198を切り捨てる、という処理ではありません。

### 4.1.E5

- 入力: Alice の年齢 `a`、Bob の年齢 `b` を読みます。
- 式: 年齢差は `a - b` または `b - a` ですが、負にしたくないので `Math.abs(a - b)` が使えます。
- 出力: 0以上の年齢差を出します。
- 注意: `a - b` だけだと、Bob の方が年上のとき負になります。

### 4.1.E6

- 入力: 円の面積 `a` を読みます。
- 式: 面積は `Math.PI * r * r` なので、半径は `Math.sqrt(a / Math.PI)` です。
- 出力: 小数でもそのまま出します。
- 注意: `Math.sqrt(a) / Math.PI` ではありません。先に `a / Math.PI` を作ってから平方根を取ります。

### 4.1.E7

- 入力: 勉強時間 `a` 分を読みます。
- 式: 時間 `h` は60分で割った商、分 `m` は `a % 60` です。商は `(a - a % 60) / 60` で作れます。
- 出力: `h`、改行、`m` の順に出します。
- 注意: `h` と `m` は別々の行です。横に並べません。

### 4.1.A1

- 入力: 勉強時間 `a` 秒を読みます。
- 式: 1時間は3600秒です。まず `h` を求め、残り秒から `m` と `s` を求めます。
- 手順: `h = (a - a % 3600) / 3600`、`rest = a % 3600`、`m = (rest - rest % 60) / 60`、`s = rest % 60` と分けると安全です。
- 注意: いきなり分と秒を出そうとすると混乱します。時間を取った残りを使います。

## 4.2 真理値

### 4.2.E1

- 入力: 整数 `a` を読みます。
- 条件: 負の数とは `0` より小さい数なので、式は `a < 0` です。
- 出力: この式の結果をそのまま出します。
- 注意: `if` で `true` / `false` を手で出す必要はありません。比較式自体が `true` または `false` になります。

### 4.2.E2

- 入力: 整数 `a` を読みます。
- 条件: 100以上は `a >= 100` です。
- 注意: 「以上」は含むので `>` ではなく `>=` です。

### 4.2.E3

- 入力: `a` と `b` を読みます。
- 条件: `a` の2乗が `b` と等しいかなので、`a * a === b` です。
- 注意: `=` は代入です。等しいか調べるには `===` を使います。

### 4.2.E4

- 入力: `a` と `b` を読みます。
- 条件: `a` の2乗が `b`、または `b` の2乗が `a` なら真です。`a * a === b || b * b === a` と書きます。
- 注意: 「どちらか一方」は `||` です。両方同時に必要な `&&` ではありません。

### 4.2.E5

- 入力: `a` と `b` を読みます。
- 条件: 商と余りを比べます。余りは `a % b`、商は `(a - a % b) / b` です。
- 出力: 2つが等しいかを `===` で出します。
- 注意: 商を `a / b` にすると小数が混ざることがあります。

### 4.2.E6

- 入力: `a`, `b`, `c` を読みます。
- 条件: 全部異なるとは、`a !== b`、`b !== c`、`c !== a` が全部成り立つことです。
- 式: `a !== b && b !== c && c !== a`。
- 注意: 2つだけ比べても足りません。3組すべて比べます。

### 4.2.E7

- 入力: 商品単価 `a` と個数 `n` を読みます。
- 条件: 総額が2000円を超えるなら送料無料です。式は `a * n > 2000` です。
- 注意: 「超えていれば」は2000ちょうどを含みません。`>=` ではなく `>` です。

### 4.2.E8

- 入力: 重さ `a`, 個数 `m`, 重さ `b`, 個数 `n` を読みます。
- 条件: 総重量が500以下、かつ総個数が10以下です。
- 式: `(a * m + b * n <= 500) && (m + n <= 10)`。
- 注意: どちらか一方ではなく、両方必要なので `&&` です。

### 4.2.E9

- 入力: 箱の数 `m` と人数 `n` を読みます。
- 条件: タルト総数は `12 * m`。余りなく分けられるなら `(12 * m) % n === 0` です。
- 注意: 余りが0なら平和に分けられます。商ではなく余りを見ます。

### 4.2.E10

- 入力: 2026年4月の日付 `d` を読みます。
- 条件: 曜日は7日ごとに繰り返します。解答コードでは `d % 7` が `4` または `5` のとき土日としています。
- 式: `let rem = d % 7; rem === 4 || rem === 5`。
- 注意: 曜日問題は、例の `5 -> true`, `14 -> false` で確認するとずれを見つけやすいです。

### 4.2.A1

- 入力: 3辺 `a`, `b`, `c` を読みます。
- 条件: 直角三角形なら、どれか1辺の2乗が他の2辺の2乗の和です。
- 式: `a*a + b*b === c*c`、`a*a + c*c === b*b`、`b*b + c*c === a*a` の3つを `||` でつなぎます。
- 注意: どの辺が斜辺かは入力順では決まりません。3通り調べます。

### 4.2.A2

- 入力: 欠席回数 `a`、遅刻回数 `b` を読みます。
- 条件: 遅刻3回を欠席1回として足します。換算欠席は `a + Math.floor(b / 3)` です。
- 出力: 換算欠席が7未満なら `true` です。
- 注意: 遅刻2回はまだ欠席1回ではありません。切り捨てが必要です。

## 4.3 文字列

### 4.3.E1

- 入力: 文字列 `a`, `b` を読みます。
- 式: 連結は `a + b` です。
- 注意: 文字列なので `Number` は使いません。

### 4.3.E2

- 入力: 文字列 `a`, `b`, `c` を読みます。
- 条件: `a + b` が `c` と等しいかを調べます。
- 式: `(a + b) === c`。
- 注意: `+` は文字列同士なら結合です。数値の足し算とは意味が変わります。

### 4.3.E3

- 入力: 文字列 `a` を読みます。
- 条件: `a === "IT" || a === "DE"` です。
- 注意: 大文字小文字は区別されます。`it` は `IT` とは別です。

### 4.3.E4

- 入力: 文字列 `a` と整数 `n` を読みます。
- 式: `Lib.charAt(a, n)` で n 文字目を取り出します。
- 注意: 最初の文字は0文字目です。1文字目ではありません。

### 4.3.E5

- 入力: 文字列 `a` を読みます。
- 式: 最初は `Lib.charAt(a, 0)`、最後は `Lib.charAt(a, Lib.length(a) - 1)` です。
- 出力: 2行で出します。
- 注意: 最後のインデクスは長さそのものではなく、長さから1引いた値です。

### 4.3.E6

- 入力: 奇数長の文字列 `a` を読みます。
- 式: 真ん中のインデクスは `(Lib.length(a) - 1) / 2` です。
- 注意: 長さが7なら真ん中は3番目です。0から数えるためです。

### 4.3.E7

- 入力: 7文字の数字文字列 `a` を読みます。
- 式: 最後4文字は `Lib.slice(a, 3, 7)` です。
- 注意: 数字だけの見た目でも、文字列として扱います。先頭の0を消さないためです。

### 4.3.E8

- 入力: 7文字の郵便番号文字列 `a` を読みます。
- 式: `Lib.slice(a, 0, 3) + "-" + Lib.slice(a, 3, 7)` です。
- 注意: `slice` の終わり位置は含まれません。`0, 3` は0,1,2文字目です。

### 4.3.E9

- 入力: 偶数長の文字列 `a` を読みます。
- 条件: 前半と後半が同じなら、同じ文字列を2回繰り返した形です。
- 手順: `half = Lib.length(a) / 2`、前半 `Lib.slice(a, 0, half)`、後半 `Lib.slice(a, half, Lib.length(a))` を比較します。
- 注意: 長さが偶数である前提を使います。

### 4.3.E10

- 入力: かっこを含む文字列 `a` を読みます。
- 式: 開きかっこは `Lib.indexOf(a, "(", 0)`。閉じかっこは、開きかっこの後から `Lib.indexOf(a, ")", open + 1)` で探します。
- 出力: 2つのインデクスを別々の行で出します。
- 注意: 閉じかっこを0から探しても、この問題では1つだけなので動きますが、「後から探す」と考える習慣が安全です。

### 4.3.E11

- 入力: かっこを含む文字列 `a` を読みます。
- 手順: E10 と同じように開きかっこと閉じかっこの位置を探し、その間を `Lib.slice(a, open + 1, close)` で切り出します。
- 注意: かっこそのものは出力しません。中身だけです。

### 4.3.E12

- 入力: `/*` と `*/` を含む文字列 `a` を読みます。
- 手順: `start = Lib.indexOf(a, "/*", 0)`、`end = Lib.indexOf(a, "*/", start + 2)` とします。
- 式: `Lib.slice(a, start, end + 2)` で `*/` まで含めます。
- 注意: `*/` は2文字なので、終わり位置に `+ 2` が必要です。

### 4.3.E13

- 入力: `DDD-DDDD-DDDD` 形式の電話番号文字列を読みます。
- 式: ハイフン以外の3部分を切り出して連結します。`slice(0,3)`, `slice(4,8)`, `slice(9,13)` です。
- 注意: 数値に変換すると先頭の0が消えるので、文字列のまま処理します。

### 4.3.E14

- 入力: 長さ8の文字列 `a` を読みます。
- 条件: 最初2文字が `TK` で、残り6文字が数字なら真です。
- 手順: `Lib.slice(a, 0, 2) === "TK"` を調べ、残りの各文字が `"0" <= ch && ch <= "9"` か確認します。
- 注意: 6文字すべてを調べます。1文字だけ数字でも足りません。

### 4.3.A1

- 入力: メールアドレス候補 `a` を読みます。
- 条件: `@` がちょうど1つ、先頭ではない、`@` の後ろに `.` がある、の3つです。
- 手順: 1つ目の `@` の位置、2つ目の `@` の位置、`@` 後の `.` の位置を `Lib.indexOf` で調べます。
- 注意: `@` がないと `indexOf` は `-1` になります。`-1` との比較を使います。

### 4.3.A2

- 入力: カンマを2つ含むCSV文字列 `a` を読みます。
- 手順: 1つ目のカンマ位置 `c1`、2つ目のカンマ位置 `c2` を探します。出す部分は `slice(0,c1)`, `slice(c1+1,c2)`, `slice(c2+1,length)` です。
- 出力: 3つの部分をそれぞれ別の行で出します。
- 注意: カンマそのものは出力しません。
