# 08. 反復文2: 問題別の詳しい解説

この章では、反復の入れ子と、個数が決まっていない入力の読み取りを練習します。長方形やひし形を描く問題では、外側のループを「行」、内側のループを「列」と決めると整理できます。入力をたくさん読む問題では、「何を読んだら終わるか」「読んだ値をどの変数にためるか」を先に決めます。

## 8.4.E1

- ループ変数: `cnt`
- 開始・停止・更新: `cnt = 1` から始め、`cnt <= k` の間続けます。毎回 `cnt = cnt + 1` で1回分進めます。
- 考え方: `k` を「値」としても「回数」としても使います。表示するたびに `cnt` で回数を数えます。
- 出力の形: `---` の後、`k` を `k` 回、同じ行に続けて出力し、最後に改行します。
- よくあるミス: ループの中で改行することです。この問題は縦ではなく横に並べます。

## 8.4.E2

- ループ変数: 外側が `k`、内側が `cnt`
- 開始・停止・更新: 外側は `k = 1` から `k <= a` まで1ずつ増やします。内側は各行で `cnt = 1` から `cnt <= k` まで1ずつ増やします。
- 考え方: 外側の `k` が「今は何行目か」と「何を何個出すか」を同時に決めます。
- 出力の形: `---` の後、1行目は `1`、2行目は `22`、3行目は `333` のように出力します。
- よくあるミス: 内側の `cnt` を外側ループの外で初期化することです。各行の先頭で `cnt = 1` に戻します。

## 8.4.E3

- ループ変数: `cnt`
- 開始・停止・更新: `cnt = 1` から始め、`cnt <= k` の間続けます。毎回 `cnt = cnt + 1` で進めます。
- 考え方: 数字の間だけコンマを出します。最後の数字の後ろにはコンマを付けません。
- 出力の形: `---` の後、`k,k,k` のように `k` を `k` 個、コンマ区切りで1行に出力します。
- よくあるミス: 最後にもコンマを出すことです。コンマは `cnt < k` のときだけ出します。

## 8.4.E4

- ループ変数: 外側が `k`、内側が `cnt`
- 開始・停止・更新: 外側は `k = 1` から `k <= a` まで進めます。内側は各行で `cnt = 1` から `cnt <= k` まで進めます。
- 考え方: 8.4.E2 にコンマ区切りの考えを加えます。各行の最後だけコンマを出さないようにします。
- 出力の形: `---` の後、各行に `k` を `k` 個、コンマ区切りで出力します。
- よくあるミス: コンマを出す条件を `cnt < a` にすることです。各行の最後は `k` 個目なので、`cnt < k` で判断します。

## 8.4.E5

- ループ変数: 外側が `row`、内側が `col`
- 開始・停止・更新: `row = 1` から `row <= b` まで進めます。各行では `col = 1` から `col <= a` まで進めます。
- 考え方: `a` は横の個数、`b` は縦の行数です。外側の1回が1行分です。
- 出力の形: `---` の後、横 `a` 個、縦 `b` 行の `O` の長方形を出力します。
- よくあるミス: `a` と `b` を逆に使うことです。

## 8.4.E6

- ループ変数: 外側が `row`、内側が `col`
- 開始・停止・更新: `row = 1` から `row <= b` まで進めます。各行で `col = 1` から `col <= a` まで進めます。
- 考え方: 文字は列ではなく行で決まります。奇数行なら `O`、偶数行なら `X` です。
- 出力の形: `---` の後、行ごとに `O` と `X` が交互に並びます。
- よくあるミス: `col` の奇数偶数で判定することです。それは列方向の交互になり、別の問題の答えになります。

## 8.4.E7

- ループ変数: 外側が `row`、内側が `col`
- 開始・停止・更新: `row = 1` から `row <= b` まで進めます。各行で `col = 1` から `col <= a` まで進めます。
- 考え方: 文字は列で決まります。奇数列なら `O`、偶数列なら `X` です。
- 出力の形: `---` の後、各行で `O`, `X`, `O`, `X` と列方向に交互に並べます。
- よくあるミス: `row` の奇数偶数で判定することです。それだと横じまになります。

## 8.4.E8

- ループ変数: 外側が `row`、内側が `col`
- 開始・停止・更新: `row = 1` から `row <= b` まで、各行で `col = 1` から `col <= a` まで進めます。
- 考え方: `row === 1`、`row === b`、`col === 1`、`col === a` のどれかなら外枠です。
- 出力の形: `---` の後、外枠が `O`、内側が `X` の長方形を出力します。
- よくあるミス: 枠の条件を `&&` でつなぐことです。上端、下端、左端、右端のどれかならよいので `||` で考えます。

## 8.4.E9

- ループ変数: 外側が `row`、内側が `col`
- 開始・停止・更新: `row = 1` から `row <= b` まで、各行で `col = 1` から `col <= a` まで進めます。
- 考え方: 左上を `O` にしたいので、`row + col` が偶数なら `O`、奇数なら `X` と考えると市松模様になります。
- 出力の形: `---` の後、`O` と `X` が交互に並ぶ長方形を出力します。
- よくあるミス: `col` だけで判定することです。行が変わっても同じ並びになり、市松模様ではなく縦じまになります。

## 8.4.E10

- ループ変数: 入力値 `a`
- 開始・停止・更新: 最初に1つ入力して `a` に入れます。`a !== 0` の間続け、ループの最後で次の入力を読み直します。
- 累積する変数: `num_odd` です。`a % 2 === 1` なら奇数として1増やします。
- 出力の形: 入力を0まで読み終えた後、`---` と奇数の個数を出力します。終了を表す0は数えません。
- よくあるミス: ループの最後で次の入力を読まないことです。同じ `a` のままになり、無限ループになります。

## 8.4.E11

- ループ変数: `cnt`
- 開始・停止・更新: 最初に個数 `n` を読みます。`cnt = 1` から `cnt <= n` まで、毎回1つずつ数を読みます。
- 累積する変数: `max` です。1個目の入力をまず最大値として扱い、その後、より大きい値を見つけたら更新します。
- 出力の形: すべて読み終えた後、`---` と最大値を1行で出力します。
- よくあるミス: `max = 0` から始めることです。将来、負の数にも対応するなら1個目を初期値にする形が安全です。

## 8.4.E12

- ループ変数: `cnt` と `i`
- 開始・停止・更新: 最初に個数 `n` とカンマ区切りの1行を読みます。`cnt = 1` から `cnt <= n` まで進め、`i` は次に読む値の開始位置として `i = j + 1` に更新します。
- 累積する変数: `min` です。切り出した `value` が今までの最小より小さければ更新します。
- 出力の形: `---` の後、カンマ区切りの数列の最小値を1行で出力します。
- よくあるミス: 最後の値で `Lib.indexOf` が `-1` になる場合を処理しないことです。最後はカンマではなく行の終わりまで切り出します。

## 8.4.E13

- ループ変数: 外側が `day`、内側が `hour`。文字列内の位置として `i` も使います。
- 開始・停止・更新: `day = 1` から `day <= n` まで進めます。各日について `hour = 1` から `hour <= 24` まで、カンマ区切りの値を24個読みます。
- 累積する変数: 各日の合計は `sum`、全体の最大合計は `max_sum`、最大だった日は `best_day` です。平均を比べても合計を比べても、24個で割る点は同じなので大小関係は同じです。
- 出力の形: `---` の後、平均気温が最も高かった日の番号を1行で出力します。
- よくあるミス: `sum`, `i`, `hour` を日ごとに初期化し忘れることです。前の日の計算が混ざります。

## 8.4.A1

- ループ変数: 外側が `row`、内側が `col`
- 開始・停止・更新: `width = 2 * n - 1` を作り、`row = 1` から `row <= width` まで進めます。各行で `col = 1` から `col <= width` まで進めます。
- 考え方: 中央からの距離で、その行の左端と右端の `O` の位置を決めます。輪郭だけ `O`、それ以外は `+` です。
- 出力の形: `---` の後、幅も高さも `2 * n - 1` のひし形の輪郭を出力します。
- よくあるミス: 幅を `n` のまま考えることです。ひし形全体の幅と高さは `2 * n - 1` です。

## 8.4.S1

- ループ変数: `i`
- 開始・停止・更新: `i = 0` から始め、`i < Lib.length(s)` の間、文字列を左から1文字ずつ読みます。
- 状態として持つもの: `ok` はここまで正しいか、`depth` は開いている括弧の数、`expect_operand` は次に `1` や `(` が必要かを表します。
- 出力の形: `---` の後、式として正しければ `true`、正しくなければ `false` を1行で出力します。
- よくあるミス: 文字列を全部読んだ後の確認を忘れることです。最後に演算子で終わっていないか、括弧が残っていないかを確認します。

## 8.4.S2

- ループ変数: サイズ計算では `cnt`、図形出力では `row` と `col`、各マスの判定では `r` と `c`
- 開始・停止・更新: まず `size = 3^n` を作ります。次に `row = 0` から `row < size`、各行で `col = 0` から `col < size` まで進めます。
- 考え方: 各マスで `r` と `c` を3で割りながら、どこかの段階で「中央の穴」に当たるかを調べます。中央に当たれば空白、そうでなければ `X` です。
- 出力の形: `---` の後、サイズ `3^n` の正方形を出力します。穴の部分は空白、残る部分は `X` です。
- よくあるミス: `r`, `c`, `is_space` をマスごとに初期化し忘れることです。前のマスの判定が次のマスに残ります。
