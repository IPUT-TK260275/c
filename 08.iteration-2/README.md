# 08. 繰り返し 2

この章では、入力を読みながら繰り返す処理や、繰り返しの中に繰り返しを書く処理を学びます。

7 章では「決まった回数だけ繰り返す」基本を学びました。この章では、「入力が続く限り読む」「特定の値が来るまで読む」「表のような形を二重ループで処理する」といった、少し実践的な繰り返しに進みます。

## この章のゴール

| 学ぶこと | 例 |
| --- | --- |
| 入力を読みながら繰り返す | `while (i < n)` |
| 終了条件つきで読む | `0` が来たら終わる |
| 繰り返しの入れ子 | `while` の中の `while` |
| 行と列を扱う | 表、盤面、文字の並び |
| 複雑な処理を分けて考える | 外側ループ、内側ループ |

## 入力回数が最初に与えられる場合

最初の入力が個数 `n` で、そのあとに `n` 個の値が続く形です。

```text
3
10
20
30
```

コードの形です。

```js
let n = Number(Lib.input());
let i = 0;
while (i < n) {
    let x = Number(Lib.input());
    // x を使う処理
    i = i + 1;
}
```

## 特定の値まで読む場合

たとえば `0` が来るまで読む形です。

```js
let x = Number(Lib.input());
while (x !== 0) {
    // x を使う処理
    x = Number(Lib.input());
}
```

ループの前で 1 回読み、ループの最後でもう一度読むのがポイントです。

## 入れ子の繰り返し

繰り返しの中に繰り返しを書くことを、入れ子と呼びます。

```js
let y = 0;
while (y < 3) {
    let x = 0;
    while (x < 4) {
        Lib.print("*");
        x = x + 1;
    }
    Lib.print("\n");
    y = y + 1;
}
```

これは `****` を 3 行出します。

外側のループは行、内側のループは列、と考えると分かりやすいです。

## 解くときの手順

1. 入力が「個数つき」か「終了値つき」か確認する。
2. 何を繰り返すかを日本語で書く。
3. 外側の繰り返しと内側の繰り返しを分けて考える。
4. カウンタをどこで初期化するか確認する。
5. カウンタをどこで更新するか確認する。
6. 出力の改行位置を最後に確認する。

## よくあるミス

| ミス | 直し方 |
| --- | --- |
| 入力を 1 行読みすぎる | 入力例の行数と `Lib.input()` の回数を比べる |
| `0` などの終了値も処理してしまう | 処理する前に終了条件を確認する |
| 内側のカウンタを外で初期化している | 内側ループの直前で初期化する |
| 改行が多い、少ない | 行が終わる場所だけ `"\n"` を出す |
| 外側と内側の変数を混ぜる | 行は `y`、列は `x` など役割で名前を分ける |

## 各問題の解説

8章は二重ループと入力を読み続ける問題が中心です。図形問題では、外側ループを「行」、内側ループを「列」と考えると整理できます。

| 問題 | 解き方の要点 |
| --- | --- |
| `8.4.E1` | 数値 `k` を文字列に変換し、`k` 回だけ結果文字列に足します。 |
| `8.4.E2` | 外側で `1` から `a` まで行番号 `k` を進め、内側で `k` を `k` 回並べます。 |
| `8.4.E3` | `k` を `k` 回並べますが、2個目以降の前にだけカンマを出します。 |
| `8.4.E4` | `8.4.E3` の処理を、`k = 1` から `a` まで繰り返します。 |
| `8.4.E5` | 外側を縦 `b` 行、内側を横 `a` 文字として、全マスに `"O"` を出します。 |
| `8.4.E6` | 行番号が奇数なら `"O"`、偶数なら `"X"` を横に `a` 個並べます。 |
| `8.4.E7` | 列番号が奇数なら `"O"`、偶数なら `"X"` を出します。各行で同じ処理をします。 |
| `8.4.E8` | 1行目、最終行、1列目、最終列なら `"O"`、それ以外は `"X"` です。 |
| `8.4.E9` | 行番号と列番号の和が偶数なら `"O"`、奇数なら `"X"` と考えます。 |
| `8.4.E10` | `0` が入力されるまで読み、奇数なら個数を増やします。`0` は数えません。 |
| `8.4.E11` | 最初に `n` を読み、次の `n` 個の整数を見ながら最大値を更新します。 |
| `8.4.E12` | カンマ区切りの1行を `Lib.indexOf` と `Lib.slice` で順に切り出し、最小値を更新します。 |
| `8.4.E13` | 各日の24個の気温を合計して平均を出し、平均が最大の日番号を更新します。 |
| `8.4.A1` | ひし形は中央行からの距離で形が決まります。境界だけ `"O"`、内側と外側は `"+"` にします。 |
| `8.4.S1` | 式の構文判定です。かっこの対応と、トップレベルの `+` で分割できるかを考えます。 |
| `8.4.S2` | サイズ `n` のカーペットは、行番号と列番号を3で割りながら中央穴に入るかを判定します。 |
