# 08. 反復文2

この章のゴールは、`while` 文の中にさらに `while` 文を書く「反復の入れ子」と、入力の個数が変わる場合の読み取り方に慣れることです。

図形を描く問題では、外側の `while` で行を進め、内側の `while` で列を進めると考えやすくなります。

## 全問を解くための型

反復の入れ子:

```js
let row = 1;
while (row <= height) {
    let col = 1;
    while (col <= width) {
        Lib.print("O");
        col = col + 1;
    }
    Lib.print("\n");
    row = row + 1;
}
```

区切り文字つきで1行を分割する型:

```js
let i = 0;
let cnt = 1;
while (cnt <= n) {
    let j = Lib.indexOf(line, ",", i);
    if (j === -1) {
        j = Lib.length(line);
    }
    let value = Number(Lib.slice(line, i, j));
    i = j + 1;
    cnt = cnt + 1;
}
```

終了値が来るまで入力を読む型:

```js
let a = Number(Lib.input());
while (a !== 0) {
    // a を使った処理
    a = Number(Lib.input());
}
```

## よくあるミス

| ミス | 直し方 |
| --- | --- |
| 内側の `while` が2行目以降で動かない | 内側のカウンタを外側の `while` の中で初期化する |
| 行末の改行がずれる | 1行分を印字し終わったところで `Lib.print("\n");` |
| カンマが余る | 最後の要素かどうかを `cnt < k` のように判定する |
| カンマ区切りの最後が読めない | `Lib.indexOf(...)` が `-1` のときは行の長さを終端にする |
