# 08. 繰り返し 2

この章では、入力を読みながら繰り返す処理や、繰り返しの中に繰り返しを書く処理を学びます。

7 章では「決まった回数だけ繰り返す」基本を学びました。この章では、「入力が続く限り読む」「特定の値が来るまで読む」「表のような形を二重ループで処理する」といった、少し実践的な繰り返しに進みます。

## この章のゴール

| 学ぶこと | 例 |
| --- | --- |
| 入力を読みながら繰り返す | `while (i < n)` |
| 終了条件つきで読む | `0` が来たら終わる |
| 繰り返しの入れ子 | `while` の中の `while` |
| 行と列を扱う | 表、盤面、文字の並び |
| 複雑な処理を分けて考える | 外側ループ、内側ループ |

## 入力回数が最初に与えられる場合

最初の入力が個数 `n` で、そのあとに `n` 個の値が続く形です。

```text
3
10
20
30
```

コードの形です。

```js
let n = Number(Lib.input());
let i = 0;
while (i < n) {
    let x = Number(Lib.input());
    // x を使う処理
    i = i + 1;
}
```

## 特定の値まで読む場合

たとえば `0` が来るまで読む形です。

```js
let x = Number(Lib.input());
while (x !== 0) {
    // x を使う処理
    x = Number(Lib.input());
}
```

ループの前で 1 回読み、ループの最後でもう一度読むのがポイントです。

## 入れ子の繰り返し

繰り返しの中に繰り返しを書くことを、入れ子と呼びます。

```js
let y = 0;
while (y < 3) {
    let x = 0;
    while (x < 4) {
        Lib.print("*");
        x = x + 1;
    }
    Lib.print("\n");
    y = y + 1;
}
```

これは `****` を 3 行出します。

外側のループは行、内側のループは列、と考えると分かりやすいです。

## 解くときの手順

1. 入力が「個数つき」か「終了値つき」か確認する。
2. 何を繰り返すかを日本語で書く。
3. 外側の繰り返しと内側の繰り返しを分けて考える。
4. カウンタをどこで初期化するか確認する。
5. カウンタをどこで更新するか確認する。
6. 出力の改行位置を最後に確認する。

## よくあるミス

| ミス | 直し方 |
| --- | --- |
| 入力を 1 行読みすぎる | 入力例の行数と `Lib.input()` の回数を比べる |
| `0` などの終了値も処理してしまう | 処理する前に終了条件を確認する |
| 内側のカウンタを外で初期化している | 内側ループの直前で初期化する |
| 改行が多い、少ない | 行が終わる場所だけ `"\n"` を出す |
| 外側と内側の変数を混ぜる | 行は `y`、列は `x` など役割で名前を分ける |
