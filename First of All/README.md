# First of All

ここは、プログラムを書く前に知っておくと一気に読みやすくなる前提知識です。

コードが分からないとき、実は `if` や `Math` ではなく、文字、数値、改行、入力、型の勘違いで止まっていることが多いです。まずここを地図にします。

## 1. 値と型

値には種類があります。この種類を型と呼びます。

| 型 | よくある名前 | 例 | 意味 |
| --- | --- | --- | --- |
| number | int, float | `123`, `3.14` | 数値 |
| string | str | `"123"`, `"abc"` | 文字列 |
| boolean | bool | `true`, `false` | 真理値 |
| undefined | undefined | `undefined` | まだ値がない |
| null | null | `null` | 意図して空にした値 |

JavaScriptでは整数も小数も、基本は `number` です。  
他の言語では、整数を `int`、小数を `float` と呼ぶことがよくあります。

```js
123      // number
3.14     // number
"123"    // string
"abc"    // string
true     // boolean
```

## 2. 数字と「数字の文字」は違う

`1` と `"1"` は別物です。

| code | 型 | 意味 |
| --- | --- | --- |
| `1` | number | 数値の1 |
| `"1"` | string | 文字の1 |
| `123` | number | 数値の123 |
| `"123"` | string | 文字列の123 |

違いが出る例:

```js
1 + 2      // 3
"1" + "2"  // "12"
```

入力は最初、文字列として読まれます。

```js
let s = Lib.input();          // string
let n = Number(Lib.input());  // number
```

数値として計算したいなら、必ず `Number(...)` を使います。

## 3. 文字と文字列

文字は1文字、文字列は文字が並んだものです。

| code | 意味 |
| --- | --- |
| `"A"` | 1文字の文字列 |
| `"Hello"` | 5文字の文字列 |
| `""` | 長さ0の文字列 |

JavaScriptでは、1文字も文字列として扱います。

```js
Lib.length("A")      // 1
Lib.length("Hello")  // 5
Lib.length("")       // 0
```

文字の位置は `0` から数えます。

```text
H e l l o
0 1 2 3 4
```

```js
Lib.charAt("Hello", 0)  // "H"
Lib.charAt("Hello", 4)  // "o"
```

## 4. ASCII

ASCIIは、文字に番号を割り当てた表です。

| 文字 | ASCII番号 |
| --- | --- |
| `"0"` | 48 |
| `"1"` | 49 |
| `"9"` | 57 |
| `"A"` | 65 |
| `"Z"` | 90 |
| `"a"` | 97 |
| `"z"` | 122 |

数字の文字は順番に並んでいるので、文字が数字かどうかはこう調べられます。

```js
"0" <= ch && ch <= "9"
```

大文字英字:

```js
"A" <= ch && ch <= "Z"
```

小文字英字:

```js
"a" <= ch && ch <= "z"
```

## 5. 改行とエスケープ

`\n` は改行を表す特別な書き方です。

```js
Lib.print("Hello\n");
Lib.print("World\n");
```

出力:

```text
Hello
World
```

よく使うエスケープ:

| code | 意味 |
| --- | --- |
| `"\n"` | 改行 |
| `"\t"` | タブ |
| `"\""` | `"` そのもの |
| `"\\"` | `\` そのもの |
| `"\0"` | null文字 |

`\` は「次の文字を特別扱いする」合図です。

```js
Lib.print("He said \"yes\".\n");
Lib.print("C:\\Users\\name\n");
```

## 6. null文字と null は違う

`"\0"` と `null` は別物です。

| code | 型 | 意味 |
| --- | --- | --- |
| `"\0"` | string | null文字を含む文字列 |
| `null` | object扱い | 値がないことを表す値 |

null文字は「文字コード0の文字」です。画面に出しても見えません。

```js
Lib.print("A\0B\n");
```

見た目は `AB` に近く見えますが、間に見えない文字があります。

授業の普通の問題では、`null` や `"\0"` を自分で使う場面はほとんどありません。ただし、名前が似ているので混ぜないようにします。

## 7. 空白も文字

スペース、タブ、改行も文字です。

| 見た目 | code | 意味 |
| --- | --- | --- |
| ` ` | `" "` | 半角スペース |
| tab | `"\t"` | タブ |
| 改行 | `"\n"` | 改行 |

出力例がこれなら、

```text
1 2
```

コードはこうです。

```js
Lib.print(1);
Lib.print(" ");
Lib.print(2);
Lib.print("\n");
```

余計な空白や改行は、採点では不正解になることがあります。

## 8. 入力は1行ずつ読む

`Lib.input()` は1行読む関数です。

入力:

```text
100
3
```

コード:

```js
let a = Number(Lib.input());
let b = Number(Lib.input());
```

1回目の `Lib.input()` は `100`、2回目は `3` を読みます。

文字列として使うなら `Number` は付けません。

```js
let name = Lib.input();
```

数値として使うなら `Number` を付けます。

```js
let age = Number(Lib.input());
```

## 9. 代入と比較は違う

`=` と `===` は違います。

| code | 意味 |
| --- | --- |
| `a = 1` | `a` に `1` を入れる |
| `a === 1` | `a` が `1` と等しいか調べる |

```js
let a = 1;
Lib.print(a === 1);
Lib.print("\n");
```

出力:

```text
true
```

## 10. まず覚える変換

| やりたいこと | code |
| --- | --- |
| 文字列を数値にする | `Number(s)` |
| 数値を文字列にする | `String(n)` |
| 値の型を調べる | `typeof x` |

例:

```js
Number("123")   // 123
String(123)     // "123"
typeof "123"    // "string"
typeof 123      // "number"
```

## 11. 最小のチェック表

問題が解けないときは、ここを順番に見ます。

1. 入力は数値か、文字列か
2. `Number(Lib.input())` が必要か
3. 出力例に `---` があるか
4. 最後に改行しているか
5. 半角スペースの数は合っているか
6. `=` と `===` を混ぜていないか
7. 文字列の位置を `0` から数えているか
8. `"\n"` を普通の `n` と勘違いしていないか
