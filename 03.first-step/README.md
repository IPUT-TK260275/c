# 03. はじめの一歩

この章では、JavaScript で値を出力し、計算し、名前を付け、入力を読む基本を学びます。

ここから本格的に `.js` ファイルを書きます。最初は「出力例と完全に同じ文字を出す」ことを意識してください。空白や改行も採点では大事です。

## この章のゴール

| 節 | 学ぶこと |
| --- | --- |
| 3.1 | 数値や文字列を出力する |
| 3.2 | 複数の文を順番に実行する |

## 基本形

この教材の JavaScript は、基本的にこの形で書きます。

```js
"use strict";
const Lib = require(require("os").homedir() + "/c/lib.js");
{
    // ここに処理を書く
}
```

`Lib.print(...)` は画面に出力します。

```js
Lib.print("Hello\n");
```

`\n` は改行です。

## 数値と文字列

数値はそのまま書けます。

```js
Lib.print(123);
Lib.print("\n");
```

文字列は `"` で囲みます。

```js
Lib.print("Hello");
Lib.print("\n");
```

計算もできます。

```js
Lib.print(100 * 3);
Lib.print("\n");
```

## 複数の出力をつなげる

出力は、書いた順番に表示されます。

```js
Lib.print("Alice: ");
Lib.print(180 * 3);
Lib.print(" yen\n");
```

出力は次のようになります。

```text
Alice: 540 yen
```

空白が必要な場所では、`" "` や `"Alice: "` のように自分で空白を書きます。

## 名前を付ける

`let` を使うと、値に名前を付けられます。

```js
let price = 180;
let count = 3;
let total = price * count;

Lib.print(total);
Lib.print("\n");
```

名前を付けると、式の意味が読みやすくなります。

## 入力を読む

`Lib.input()` は入力を 1 行読みます。

文字列として読む場合です。

```js
let name = Lib.input();
Lib.print("Hello, ");
Lib.print(name);
Lib.print("!\n");
```

数値として読む場合は `Number(...)` で変換します。

```js
let price = Number(Lib.input());
let count = Number(Lib.input());

Lib.print(price * count);
Lib.print("\n");
```

## 入力つきで実行する

入力例が次のように 2 行あるとします。

```text
100
3
```

ターミナルでは、次のように実行できます。

```bash
printf '100\n3\n' | node 03.first-step/3.4.E1.js
```

## 問題ファイルの目安

| ファイル | 内容 |
| --- | --- |
| `3.1.1.E1.js` から `3.1.1.E12.js` | 数値や式の出力 |
| `3.1.2.E1.js` から `3.1.2.E3.js` | 文字列の出力 |
| `3.2.E1.js`, `3.2.E2.js` | 文を順番に並べる |
| `3.3.E1.js` から `3.3.E3.js` | 名前を使う |
| `3.4.E1.js` から `3.4.E7.js` | 入力を読む |
| `Numbers.*.js` | 数値の例 |
| `Strings.*.js` | 文字列の例 |
| `Input.*.js` | 入力の例 |

## よくあるミス

| ミス | 直し方 |
| --- | --- |
| 文字列を `"` で囲んでいない | `"Hello"` のように囲む |
| 最後の改行がない | `Lib.print("\n");` を足す |
| 数値入力を文字列のまま計算している | `Number(Lib.input())` を使う |
| 出力例と空白が違う | 出力例を 1 文字ずつ見る |
| 変数名を間違える | `price` と `prcie` のようなスペル違いを探す |

## 各問題の解説

まず「何を出力するか」を決め、最後に出力例と同じ改行を入れます。数値入力を計算に使う問題では、必ず `Number(Lib.input())` で数値に変換します。

| 問題 | 解き方の要点 |
| --- | --- |
| `3.1.1.E1` | `3 - 5 - 7` をそのまま式として `Lib.print` に渡します。左から計算されます。 |
| `3.1.1.E2` | かっこがあるので `3 - (5 - 7)` と書きます。E1 とは計算順序が違います。 |
| `3.1.1.E3` | 掛け算は `*` で書きます。`3 - 5 * 7` は掛け算が先です。 |
| `3.1.1.E4` | 先に `3 - 5` を計算したいので `(3 - 5) * 7` と書きます。 |
| `3.1.1.E5` | 分数は割り算 `/` で表します。`2 + 3 / 5` のように書きます。 |
| `3.1.1.E6` | 分母全体を先に作るなら、必要な部分をかっこで囲みます。 |
| `3.1.1.E7` | 分数部分と `+ 7` を分けて考え、割り算の範囲をかっこで明確にします。 |
| `3.1.1.E8` | 時給と勤務時間を掛けます。`1163 * 79` が賃金です。 |
| `3.1.1.E9` | Alice と Bob それぞれの賃金を計算して足します。 |
| `3.1.1.E10` | 果物代は `180 * 120 + 120 * 160`、1人分はそれを `80` で割ります。 |
| `3.1.1.E11` | 全体の果物代から教員負担 `30000` を引き、その残りを `80` で割ります。 |
| `3.1.1.E12` | 税抜合計に `1.1` を掛けて税込合計にし、それを `80` で割ります。 |
| `3.1.2.E1` | 表示したい英文をそのまま文字列リテラルにします。 |
| `3.1.2.E2` | 2行に分けるので、途中に `\n` を入れます。 |
| `3.1.2.E3` | 日本語も文字列として `"` で囲めば出力できます。 |
| `3.2.E1` | Alice, Bob, Carol の代金をそれぞれ計算し、ラベル、数値、` yen\n` を順に出力します。 |
| `3.2.E2` | アスキーアートは空白も文字です。各行を文字列として正確に出力します。 |
| `3.3.E1` | 単価、個数、人数に名前を付けてから、合計金額と1人分を計算します。 |
| `3.3.E2` | 果物の単価を名前にし、各人の購入内容を式にします。出力形式は `3.2.E1` と同じです。 |
| `3.3.E3` | `3.3.E2` の単価だけを変更します。名前を使っていれば計算式はほぼそのままです。 |
| `3.4.E1` | 単価 `a` と個数 `m` を入力し、`a * m` を出力します。 |
| `3.4.E2` | 名 `a` と姓 `b` を文字列で読み、指定された順番で文に埋め込みます。 |
| `3.4.E3` | りんご代と桃代を足し、消費税として `1.1` を掛けます。 |
| `3.4.E4` | 商品名は文字列、価格と個数は数値として読みます。各商品の小計と合計を出します。 |
| `3.4.E5` | 入力 `a`、`a * a`、`a * a * a` を3行に出します。 |
| `3.4.E6` | 文字列 `a` をそのまま、2回連結、3回連結して出力します。 |
| `3.4.E7` | 5つの数値を読み、合計を `5` で割って平均を出します。 |
