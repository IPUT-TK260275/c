# 03. はじめの一歩 問題別の詳しい解説

このファイルは、3章の練習問題を「何から考えればよいか」から説明するためのものです。まず問題文を読み、入力があるか、出力だけかを分けて考えます。

## 最初に使う基本形

どの問題も、まずこの形から始めます。

```js
"use strict";
const Lib = require(require("os").homedir() + "/c/lib.js");
{
    // ここに処理を書く
}
```

数値を読むときは `Number(Lib.input())`、文字列を読むときは `Lib.input()` です。出力の最後には、出力例に合わせて `Lib.print("\n");` を入れます。

## 3.1.1 数値の問題

### 3.1.1.E1

- 目的: `3 - 5 - 7` の計算結果を出す問題です。
- 考え方: 入力はありません。`Lib.print(3 - 5 - 7);` のように、式をそのまま書けます。
- 注意: `-` は左から順に計算されます。最後に改行を出すなら、次の行で `Lib.print("\n");` と書きます。

### 3.1.1.E2

- 目的: `3 - (5 - 7)` の計算結果を出します。
- 考え方: E1 と似ていますが、かっこの中を先に計算します。式にも必ずかっこを書きます。
- 注意: `3 - 5 - 7` と書くと別の計算になります。問題文のかっこをそのままコードへ写します。

### 3.1.1.E3

- 目的: `3 - 5 * 7` を計算します。
- 考え方: 掛け算は `*` で書きます。JavaScript でも掛け算が引き算より先に計算されます。
- 注意: 数学の `×` は使いません。キーボードで書く記号は `*` です。

### 3.1.1.E4

- 目的: `(3 - 5) * 7` を計算します。
- 考え方: 先に `3 - 5` を計算したいので、コードにも `(3 - 5)` と書きます。
- 注意: かっこを忘れると `3 - 5 * 7` になり、答えが変わります。

### 3.1.1.E5

- 目的: 分数を含む式をコードで表します。
- 考え方: 分数は `/` で書きます。たとえば「3分の5」ではなく「3を5で割る」なら `3 / 5` です。
- 注意: 分母や分子が複数の項からなる場合は、必ずかっこで範囲を示します。

### 3.1.1.E6

- 目的: 掛け算と割り算が混ざった分数式を出します。
- 考え方: まず「分子はどこか」「分母はどこか」を日本語で区切ります。分母全体が `5 + 7` なら `(5 + 7)` とします。
- 注意: `/` の右側にそのまま `5 + 7` と書くと、意図と違う順番で計算されることがあります。

### 3.1.1.E7

- 目的: 分数部分と足し算部分を組み合わせます。
- 考え方: 分数で計算する部分を先に作り、その後に `+ 7` を付けます。
- 注意: 「どこまでが割られる式か」をかっこで明確にします。

### 3.1.1.E8

- 目的: Alice の賃金を出します。
- 考え方: 賃金は「時給 × 勤務時間」です。式は `1163 * 79` です。
- 注意: 円は数値に含めません。数値だけを印字します。

### 3.1.1.E9

- 目的: Alice と Bob の賃金の合計を出します。
- 考え方: Alice は `1163 * 79`、Bob は `1163 * 182` です。この2つを足します。
- 注意: 先にそれぞれの賃金をかっこで囲むと読みやすくなります。

### 3.1.1.E10

- 目的: 果物代を学生80人で割った1人分を出します。
- 考え方: りんご代は `180 * 120`、オレンジ代は `120 * 160`。合計を `80` で割ります。
- 注意: `180 * 120 + 120 * 160 / 80` と書くと、オレンジ代だけが80で割られます。合計全体を割るためにかっこを使います。

### 3.1.1.E11

- 目的: 教員が30000円負担した後の、学生1人分を出します。
- 考え方: まず果物代の合計を出します。そこから `30000` を引き、残りを `80` で割ります。
- 注意: 引く位置を間違えないでください。「1人分から30000を引く」のではありません。

### 3.1.1.E12

- 目的: 消費税10%込みで1人分を出します。
- 考え方: 税抜の果物代合計を作り、税込にするために `1.1` を掛けます。それを `80` で割ります。
- 注意: 税率10%は `10` ではなく、合計金額に掛ける係数として `1.1` を使います。

## 3.1.2 文字列の問題

### 3.1.2.E1

- 目的: 指定された英文をそのまま出します。
- 考え方: 英文全体を `"` で囲みます。最後に `\n` を含めてもよいです。
- 注意: ピリオドや空白も出力の一部です。問題文と同じ文字列にします。

### 3.1.2.E2

- 目的: 2行の英文を出します。
- 考え方: 1つの文字列の中に `\n` を入れるか、2回 `Lib.print` します。
- 注意: `Love me,` の後に改行が必要です。空白を入れて1行にしないようにします。

### 3.1.2.E3

- 目的: 日本語を含む文字列を出します。
- 考え方: 日本語も文字列なので `"課題っ......... 圧倒的課題...!"` のように囲めます。
- 注意: 点の数や空白も採点では違いになります。コピーしてから確認すると安全です。

## 3.2 文を並べる問題

### 3.2.E1

- 目的: Alice, Bob, Carol の支払額を指定形式で出します。
- 考え方: それぞれの買い物代を計算し、`"Alice: "`、数値、`" yen\n"` の順で出力します。
- 注意: ラベル、コロン、空白、`yen`、改行を出力例と同じにします。

### 3.2.E2

- 目的: 文字で絵を描く問題です。
- 考え方: 各行を文字列として出します。5行あるなら、5回出力してもよいです。
- 注意: 先頭や途中の空白も絵の一部です。見た目がずれると不正解になりやすいです。

## 3.3 名前を使う問題

### 3.3.E1

- 目的: 果物代の1人分を、名前を使って計算します。
- 考え方: `price_apple`, `number_apples`, `price_orange`, `number_oranges`, `number_students` を先に作ります。合計金額を作り、人数で割ります。
- 注意: 数字を式に直接たくさん書くと読みにくくなります。この問題では指定された名前を使います。

### 3.3.E2

- 目的: Alice, Bob, Carol の支払額を名前付きの値で計算します。
- 考え方: 果物の単価を変数にし、各人の購入数を掛けて足します。たとえば Alice はりんご3つとオレンジ2つです。
- 注意: 誰が何を何個買ったかを混ぜないよう、先に紙やコメントで整理すると安全です。

### 3.3.E3

- 目的: E2 と同じ買い物で、単価だけ変えます。
- 考え方: `price_apple`, `price_orange`, `price_banana` の値だけ変えれば、計算式はほぼ同じまま使えます。
- 注意: 名前を使う利点を確認する問題です。式の中の数字を全部探して直す必要はありません。

## 3.4 入力を読む問題

### 3.4.E1

- 目的: 単価と個数を入力し、代金を出します。
- 考え方: `a` と `m` は数値なので `Number(Lib.input())` で読みます。答えは `a * m` です。
- 注意: 入力を文字列のままにしないでください。

### 3.4.E2

- 目的: 名と姓を入力し、指定された英文に埋め込みます。
- 考え方: 名 `a`、姓 `b` は文字列で読みます。出力では先に `b`、後で `a` を使います。
- 注意: 入力順と出力順が違います。ここが一番間違いやすいです。

### 3.4.E3

- 目的: りんごと桃の税込代金を出します。
- 考え方: 4つの数値を読み、`a * m + b * n` で税抜合計を作ります。税込は `* 1.1` です。
- 注意: 小数のままでよい問題なので、切り捨て処理は不要です。

### 3.4.E4

- 目的: 商品名2つと、それぞれの小計と合計を出します。
- 考え方: 商品名は文字列、価格と個数は数値で読みます。`p = a * m`, `q = b * n`, `t = p + q` と分けると楽です。
- 注意: `===` の行、`Total` の行、`yen` の位置を出力例に合わせます。

### 3.4.E5

- 目的: 入力した整数、その2乗、3乗を出します。
- 考え方: `a`, `a * a`, `a * a * a` を順に出します。
- 注意: `a2` のように書いても2乗にはなりません。掛け算を明示します。

### 3.4.E6

- 目的: 入力文字列を1回、2回、3回並べて出します。
- 考え方: 文字列の結合は `+` です。`a + a`、`a + a + a` を使います。
- 注意: 数値ではなく文字列なので、`Number` は使いません。

### 3.4.E7

- 目的: 5つの数値の平均を出します。
- 考え方: 5回入力を読み、全部足して `5` で割ります。
- 注意: 入力を読む回数が5回であることを確認します。最後に `---` の後で平均だけを出します。
