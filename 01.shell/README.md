# 01. Shell

この章のゴールは、ターミナルで「今どこにいるか」「何があるか」「ファイルを作る・見る・探す・消す」ができるようになることです。

Shell は、文字でコンピュータに命令する場所です。  
コマンドは基本的にこの形で書きます。

```bash
コマンド オプション 引数
```

例:

```bash
ls -la 03.first-step
```

| 部分 | 意味 |
| --- | --- |
| `ls` | コマンド |
| `-la` | オプション |
| `03.first-step` | 対象 |

## 1. 場所を確認する

### pwd

`pwd` は、今いる場所を表示するコマンドです。

```bash
pwd
```

`print working directory` の略です。

### cd

`cd` は、ディレクトリを移動するコマンドです。

```bash
cd 03.first-step
```

`change directory` の略です。

よく使う移動:

| command | 意味 |
| --- | --- |
| `cd フォルダ名` | そのフォルダに入る |
| `cd ..` | 1つ上の階層に戻る |
| `cd ~` | ホームディレクトリに戻る |
| `cd -` | 直前にいた場所に戻る |

場所を表す記号:

| 記号 | 意味 |
| --- | --- |
| `.` | 今の場所 |
| `..` | 親ディレクトリ |
| `~` | ホームディレクトリ |
| `-` | 直前の場所 |

## 2. 中身を見る

### ls

`ls` は、その場所に何があるか表示するコマンドです。

```bash
ls
```

よく使うオプション:

| command | 意味 |
| --- | --- |
| `ls` | ファイル名だけ表示 |
| `ls -l` | 詳細表示 |
| `ls -a` | 隠しファイルも表示 |
| `ls -la` | 詳細表示 + 隠しファイル |

### ls -l の読み方

例:

```text
-r--r-xr-x 1 XX XX 40 Jun 1 23:42 testShell00
```

最初の `-r--r-xr-x` は、4つに分けて読みます。

```text
- / r-- / r-x / r-x
```

| 部分 | 意味 |
| --- | --- |
| `-` | ファイルの種類 |
| `r--` | 所有者の権限 |
| `r-x` | グループの権限 |
| `r-x` | その他の人の権限 |

ファイルの種類:

| 記号 | 意味 |
| --- | --- |
| `-` | 普通のファイル |
| `d` | ディレクトリ |
| `l` | シンボリックリンク |

権限:

| 記号 | 意味 |
| --- | --- |
| `r` | 読み取り |
| `w` | 書き込み |
| `x` | 実行 |
| `-` | 権限なし |

残りの部分:

| 部分 | 意味 |
| --- | --- |
| `1` | リンク数 |
| `XX` | 所有者名 |
| `XX` | グループ名 |
| `40` | ファイルサイズ。40バイト |
| `Jun 1 23:42` | 更新日時 |
| `testShell00` | ファイル名 |

## 3. 開く

### open

`open` は、ファイルやフォルダを既定のアプリで開くコマンドです。

```bash
open .
```

`open .` は、今いるフォルダを Finder で開きます。

### code

`code` は、Visual Studio Code で開くコマンドです。

```bash
code .
```

`code .` は、今いるフォルダを VS Code で開きます。

## 4. 作る

### mkdir

`mkdir` は、ディレクトリを作るコマンドです。

```bash
mkdir test
```

`make directory` の略です。  
この例では、`test` というディレクトリを作ります。

### touch

`touch` は、空ファイルを作る、または更新日時を変えるコマンドです。

```bash
touch file.txt
```

`file.txt` がなければ作ります。  
すでにあれば、中身は変えずに更新日時だけ変えます。

## 5. 消す

### rm

`rm` は、ファイルを削除するコマンドです。

```bash
rm file.txt
```

`remove` の略です。

ディレクトリごと消すとき:

```bash
rm -r dir
```

よく使うオプション:

| option | 意味 |
| --- | --- |
| `-r` | ディレクトリの中身ごと削除 |
| `-f` | 確認なしで強制削除 |

`rm` で消したものは、普通はゴミ箱に入りません。特に `rm -r` と `rm -f` は慎重に使います。

### rmdir

`rmdir` は、空のディレクトリだけ削除できるコマンドです。

```bash
rmdir emptydir
```

中にファイルがあるディレクトリは消せません。

## 6. ファイルの中身を見る・出す

### cat

`cat` は、ファイルの中身をそのまま表示するコマンドです。

```bash
cat file.txt
```

### echo

`echo` は、文字列を表示するコマンドです。最後に改行が入ります。

```bash
echo hello
```

### printf

`printf` も文字列を表示するコマンドです。改行は自分で書きます。

```bash
printf 'hello\n'
```

入力つきでプログラムを実行するときにも使えます。

```bash
printf '100\n3\n' | node 03.first-step/3.4.E1.js
```

## 7. 出力先を変える

### リダイレクト

`>` は、出力先を画面ではなくファイルに向ける記号です。

```bash
echo hello > file.txt
```

この例では、`hello` を `file.txt` に書きます。

| 記号 | 意味 |
| --- | --- |
| `>` | 上書き出力 |
| `>>` | 追記 |
| `<` | ファイルを入力として渡す |
| `2>` | エラー出力を書き出す |

例:

```bash
echo first > memo.txt
echo second >> memo.txt
cat memo.txt
```

出力:

```text
first
second
```

## 8. コマンドをつなぐ

### パイプ

`|` は、左のコマンドの出力を、右のコマンドの入力に渡す記号です。

```bash
ls | grep txt
```

この例では、`ls` の結果から `txt` を含む行だけ探します。

コマンドをつなぐ記号:

| 記号 | 意味 |
| --- | --- |
| `|` | 左の出力を右へ渡す |
| `&&` | 左が成功したら右を実行 |
| `||` | 左が失敗したら右を実行 |
| `;` | 成功・失敗に関係なく次を実行 |
| `&` | バックグラウンドで実行 |

## 9. ワイルドカード

`*` は、「何でもいい文字列」を表すワイルドカードです。

```bash
ls *.txt
```

この例では、`.txt` で終わるファイルを表示します。

よくある例:

| pattern | 意味 |
| --- | --- |
| `*.txt` | `.txt` で終わる |
| `test*` | `test` で始まる |
| `*test*` | `test` を含む |

## 10. 履歴と補完

| 操作 | 意味 |
| --- | --- |
| `↑キー` | 直前に打ったコマンド履歴を呼び出す |
| `Tab` | ファイル名やディレクトリ名を補完する |
| `history` | コマンド履歴の一覧を見る |

長いファイル名は、途中まで打って `Tab` を押すと楽です。

## 11. 探す・加工する

### grep

`grep` は、文字列を検索するコマンドです。

```bash
grep hello file.txt
```

この例では、`file.txt` の中から `hello` を含む行を探します。

### find

`find` は、ファイルやディレクトリを探すコマンドです。

```bash
find . -name '*.js'
```

この例では、今いる場所以下から `.js` で終わるファイルを探します。

### tr

`tr` は、文字を置き換えたり削除したりするコマンドです。

```bash
echo abc | tr abc ABC
```

出力:

```text
ABC
```

削除:

```bash
echo 'a-b-c' | tr -d '-'
```

出力:

```text
abc
```

### sed

`sed` は、文字列の置換や行編集をするコマンドです。

```bash
echo hello | sed 's/hello/HELLO/'
```

出力:

```text
HELLO
```

### awk

`awk` は、列ごとに処理したり、条件に応じて抜き出したりするコマンドです。

```bash
echo 'apple 100' | awk '{ print $1 }'
```

出力:

```text
apple
```

`$1` は1列目、`$2` は2列目です。

### sort

`sort` は、行を並べ替えるコマンドです。

```bash
printf 'banana\napple\ncherry\n' | sort
```

出力:

```text
apple
banana
cherry
```

## 12. 権限とリンク

### chmod

`chmod` は、権限を変えるコマンドです。

```bash
chmod +x script.sh
```

`change mode` の略です。  
この例では、`script.sh` を実行できるようにします。

### ln

`ln` は、リンクを作るコマンドです。

```bash
ln original.txt hardlink.txt
```

シンボリックリンクを作るとき:

```bash
ln -s original.txt shortcut.txt
```

| 種類 | 意味 |
| --- | --- |
| ハードリンク | 同じ実体に別名を付ける |
| シンボリックリンク | 別ファイルへのショートカットを作る |

## 13. アーカイブ

### tar

`tar` は、複数のファイルをひとまとめにするコマンドです。

アーカイブを作る:

```bash
tar -cf archive.tar file1.txt file2.txt
```

中身を見る:

```bash
tar -tf archive.tar
```

| option | 意味 |
| --- | --- |
| `-c` | create。作成 |
| `-t` | table。中身一覧 |
| `-f` | file。アーカイブファイル名を指定 |

## 14. ファイル種別と Magic File

### file

`file` は、ファイルの種類を判定するコマンドです。

```bash
file README.md
```

拡張子だけでなく、ファイルの中身も見て判定します。

### Magic File

Magic File は、`file` コマンドがファイル種別を判定するためのルールです。

基本の形:

```text
<offset> <type> <value> <description>
```

| 部分 | 意味 |
| --- | --- |
| `<offset>` | ファイルの何バイト目を見るか |
| `<type>` | どういう型として読むか |
| `<value>` | 何と一致したら判定するか |
| `<description>` | 一致したときに表示する説明 |

例:

```text
0 string HELLO hello text
```

これは、ファイルの先頭が `HELLO` なら `hello text` と判定する、という意味です。

## 15. 差分を見る・適用する

### diff

`diff` は、2つのファイルの違いを見るコマンドです。

```bash
diff old.txt new.txt
```

パッチ形式で見る:

```bash
diff -u old.txt new.txt
```

### patch

`patch` は、差分ファイルをもとに変更を適用するコマンドです。

```bash
patch < changes.patch
```

`diff -u` で作った差分を、あとから別のファイルに反映するときに使います。

## 16. プロセスを見る・止める

### top

`top` は、今動いているプロセスをリアルタイムで見るコマンドです。

```bash
top
```

終了するときは `q` を押します。

### pkill

`pkill` は、名前でプロセスを終了するコマンドです。

```bash
pkill node
```

この例では、名前に `node` が合うプロセスを終了します。  
関係ないプロセスまで止めないように、名前をよく確認してから使います。

## 17. 画面をきれいにする

### clear

`clear` は、ターミナルの画面をきれいにするコマンドです。

```bash
clear
```

画面表示が流れすぎたときに使います。
