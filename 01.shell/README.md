# 01. Shell

この章では、ターミナルでファイルやフォルダを操作する基本を学びます。

プログラミングを始めたばかりの人にとって、ターミナルは少し怖く見えます。でも、この章で使う操作はほとんど決まっています。まずは「今どこにいるかを見る」「中身を見る」「場所を移動する」「ファイルを実行する」だけできれば大丈夫です。

## この章のゴール

この章が終わるころには、次のことができるようになります。

| できること | 使うコマンド |
| --- | --- |
| 今いる場所を確認する | `pwd` |
| フォルダの中身を見る | `ls` |
| フォルダを移動する | `cd` |
| ファイルの中身を見る | `cat` |
| 文字を出力する | `echo`, `printf` |
| プログラムに入力を渡す | `printf ... \| node ...` |

## まず覚える 3 つ

### `pwd`

`pwd` は、今ターミナルがいる場所を表示します。

```bash
pwd
```

この教材では、基本的に `~/c` の中で作業します。

### `ls`

`ls` は、今いる場所にあるファイルやフォルダを表示します。

```bash
ls
```

詳しく見たいときは次のようにします。

```bash
ls -la
```

### `cd`

`cd` は、別のフォルダへ移動します。

```bash
cd 03.first-step
```

1 つ上のフォルダへ戻るときは、次のようにします。

```bash
cd ..
```

## 場所を表す記号

| 記号 | 意味 |
| --- | --- |
| `.` | 今いるフォルダ |
| `..` | 1 つ上のフォルダ |
| `~` | 自分のホームフォルダ |
| `~/c` | この教材を置く想定のフォルダ |

たとえば、どこにいても教材フォルダへ戻りたいときはこうします。

```bash
cd ~/c
```

## ファイルの中身を見る

`cat` は、ファイルの中身をターミナルに表示します。

```bash
cat README.md
```

長いファイルは一気に流れるので、まずは短いファイルで試してください。

## 文字を出す

`echo` は文字を出力します。

```bash
echo hello
```

`printf` も文字を出力します。改行を自分で書けるので、プログラムに入力を渡すときによく使います。

```bash
printf '100\n3\n'
```

`\n` は改行です。上の例は `100` と `3` を 2 行で出力します。

## プログラムに入力を渡す

この教材では、入力例を使ってプログラムを試すことがよくあります。

```bash
printf '100\n3\n' | node 03.first-step/3.4.E1.js
```

`|` は、左のコマンドの出力を右のコマンドの入力として渡す記号です。

上の例では、`100` と `3` を `03.first-step/3.4.E1.js` に入力しています。

## よく使うコマンド一覧

| コマンド | 何をするか |
| --- | --- |
| `pwd` | 今いる場所を見る |
| `ls` | 中身を見る |
| `ls -la` | 隠しファイルも含めて詳しく見る |
| `cd フォルダ名` | フォルダへ移動する |
| `cd ..` | 1 つ上へ戻る |
| `cd ~/c` | 教材フォルダへ移動する |
| `cat ファイル名` | ファイルの中身を見る |
| `echo 文字` | 文字を出力する |
| `printf '文字\n'` | 改行つきで文字を出力する |
| `node ファイル名.js` | JavaScript を実行する |
| `node --check ファイル名.js` | 文法だけ確認する |

## 困ったとき

まず次の 3 つを打ってください。

```bash
pwd
ls
node --version
```

`README.md` や `03.first-step` が `ls` で見えない場合は、教材フォルダにいません。

```bash
cd ~/c
```

で戻ってから、もう一度試してください。
